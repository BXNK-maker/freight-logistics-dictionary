# 货运物流词典 15000 词条整体规划方案

> 版本 v1.0 ｜ 2026-10-23 ｜ 基于现有 1240 条已上线成果（bxnk-maker.github.io/freight-logistics-dictionary）
> 目标：在不改变「GitHub Actions + Gemini 自动生成 + Pages 托管」架构的前提下，将词条总量从 1240 扩充至 15000。

---

## 一、总体思路

现有流水线已验证跑通（1240 条全量上线），扩容的真正瓶颈不是**生成**（脚本自动化），而是两件事：

1. **词条来源**：13760 条新词的"英文术语 + 中文译名 + 分类"清单从哪来；
2. **质量控制**：数量放大 12 倍后，如何防止质量稀释和重复词条。

因此整体方案 = **分类体系升级 → 词条来源四通道 → 分阶段批量实施 → 三层质量控制**。

## 三、词条来源：四通道策略

| 通道 | 方式 | 预计产出 | 说明 |
|-----|------|--------:|-----|
| A. 权威词表导入 | 整理公开领域词表（维基百科物流/贸易类目、Incoterms 2020 全集、FIATA/IATA 公开术语页、海关总署公开词汇）为 CSV | ~3,500 | 只用可自由使用的来源，README 注明来源清单；这是**最快**的通道 |
| B. 标准代码表映射 | HS 编码 4 位品目标题（~1,250）、全球主要集装箱港口（~800）、IATA 货运机场三字码（~500）、集装箱类型/危险品类别代码（~150） | ~2,700 | 结构化数据 → 词条模板，几乎零成本，天然去重 |
| C. LLM 关联扩展 | 以已确认词条为种子，让 Gemini 批量生成「同义词、缩写、上下游关联术语、行业俗称」，人工去重后入库 | ~6,500 | 长尾主力；每轮扩展 500 词，与去重管线配合 |
| D. 补遗与纠错 | 用户搜索词缺口（接入搜索日志）、抽检发现的新词 | ~1,060 | 持续进行，兜底凑足 15,000 |

**去重是 A/C 通道的生命线**：三级去重（精确匹配 → 归一化匹配（大小写/连字符/全半角）→ 三元组相似度 ≥0.85 拦截），中英文各查一遍。

## 六、质量控制体系（三层）

### 第一层：生成前——词源准入
- 通道 A 词表仅采信公开领域/官方来源，登记《词源台账》（来源、许可、条数）；
- 每个词条入库前必过三级去重 + 分类合法性校验（分类必须属于 12 个一级分类之一）。

### 第二层：生成中——模板与校验
- Prompt 模板 v2 统一词条结构：**英文术语 / 中文译名 / 缩写 / 一句话定义 / 应用场景 / 相关术语（3–5 个互链）**，缺字段即判失败重生成；
- 生成结果过 JSON/正则结构校验，脏数据直接进重试队列，不入库。

### 第三层：生成后——CI 与抽检
| 检查项 | 方式 | 频率 |
|-------|------|-----|
| Front-matter 完整性、slug 唯一、分类合法 | GitHub Actions CI 脚本 | 每次推送 |
| 全库语义去重扫描 | 本地脚本（相似度阈值） | 每阶段末 |
| 人工抽检 5%（25 条/批） | 按定义准确性、中文地道度、分类归属打分 | 每批 |
| 搜索与链接健康度 | 构建日志 + 相关术语互链抽查 | 每周 |

## 七、验收标准

**每批次验收（500 条）**：
1. 数量足额，无 pending 残留；
2. 词条三要素（英文名/中文名/定义）完整率 **100%**；
3. 抽检 25 条合格率 **≥ 96%**（合格定义：定义准确、无事实错误、分类正确、中文通顺）——不达标整批打回重生成；
4. 与已有词条重复率 **= 0**（去重管线报告为准）。

**整体验收（15,000 条，第 12 周末）**：
1. 各一级分类数量与规划表偏差 **≤ ±5%**；
2. 全库抽检 300 条（每分类 25 条）综合合格率 **≥ 95%**；
3. 全库无重复词条、无死链，相关术语互链覆盖率 ≥ 80%；
4. 网站构建零错误，二级分类导航/首字母索引/搜索全部可用，构建时间 ≤ 6 分钟；
5. 《词源台账》完整，README 附数据来源与许可声明。

## 八、主要风险与对策

| 风险 | 影响 | 对策 |
|-----|-----|-----|
| Gemini 配额熔断（429） | 生成中断 | 付费层根治；或多 Key 轮换 + 模型降级链（已就绪） |
| 长尾词条质量稀释 | 抽检不合格率高 | 阶段 2/3 每批抽检放行制；连续 2 批不达标则降速换种子词 |
| 通道 A 词源版权 | 法律风险 | 只用公开领域来源 + 台账留痕；不用商业词库内容 |
| 分类漂移（LLM 归类错） | 导航混乱 | 分类白名单校验 + 抽检项 + 阶段末全库重归类脚本 |
| 仓库/站点性能 | 构建变慢、搜索卡顿 | 搜索索引分片；每 1,000 条打一个 release tag 存档 |
| PAT/Key 失效 | 自动化停摆 | PAT 到期前 1 周更换；Key 存 Secrets 轮换 |

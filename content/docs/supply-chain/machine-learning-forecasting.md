> 📖 分类：**供应链管理** / 计划体系　｜　Machine Learning Forecasting = 机器学习预测

## 定义
Machine Learning Forecasting（机器学习预测）是指利用历史货运数据、市场趋势及外部变量（如天气、汇率、节假日等），通过算法模型自动学习并预测未来物流需求、运价波动或库存水平的技术。它是现代智慧供应链的核心驱动力之一，能够显著提升供应链的预测准确率和响应速度。

## 详细说明
- 使用场景：广泛应用于海运/空运舱位需求预测、国际干线运价走势分析、仓库备货量规划以及跨境电商爆品销量预估。
- 关键规则或数字：传统预测准确率通常在60%-70%左右，而引入Machine Learning Forecasting后，在数据质量良好的情况下，预测准确率可提升至85%-90%以上，并将人工制表时间缩短70%以上。
- 实务注意事项：算法效果高度依赖历史数据的完整性与清洁度；同时，需警惕黑天鹅事件（如港口罢工、地缘政治冲突）导致的模型失效，必须结合人工经验进行动态修正。

## 常见误区
- 认为机器学习预测可以完全脱离人工干预：算法无法完全预知突发政策变动或极端天气，必须结合物流专家的行业经验进行复核。
- 盲目追求复杂的算法模型：数据量不足时，复杂的深度学习模型效果往往不如简单的线性回归或时间序列模型，应根据实际业务规模选择合适的算法。

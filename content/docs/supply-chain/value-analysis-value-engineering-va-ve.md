> 📖 分类：**供应链管理** / 采购管理　｜　Value Analysis / Value Engineering (VA/VE) = 价值分析与价值工程

## 定义

Value Analysis / Value Engineering (VA/VE，价值分析与价值工程) 是一种通过系统性审查产品或服务的成本与功能，旨在确保以最低的全生命周期成本实现必要功能的管理方法。在国际货运与物流领域，它常被用来优化供应链设计、包装规范和运输路线，从而在不降低服务质量的前提下实现显著的成本节约。

## 详细说明

- 使用场景：通常应用于新物流方案的设计阶段、现有供应链网络的大规模成本优化、大宗货物运输包装的改进，以及仓储自动化改造项目的评估。
- 关键规则或数字：VA 指对现有物流服务或产品进行事后分析和改进；VE 则是在设计研发阶段进行事前预防。常见的优化目标是在保证交付时效和安全的前提下，削减 10% 至 30% 的综合物流成本。
- 实务注意事项：在进行物流 VA/VE 时，必须同步评估成本缩减对货损率、清关效率和客户满意度的潜在负面影响，避免因过度追求低成本而导致整体供应链韧性下降。

## 常见误区

- 误认为 VA/VE 等同于单纯的降价压价：实际上它是通过技术和流程创新来提升性价比，而非简单粗暴地削减服务标准。
- 忽视隐性成本：只关注直接的运费或仓储费降低，而忽略了可能因此增加的库存持有成本或货损赔偿风险。

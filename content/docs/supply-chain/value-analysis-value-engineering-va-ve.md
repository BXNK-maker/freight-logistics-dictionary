> 📖 分类：**供应链管理** / 采购管理　｜　Value Analysis / Value Engineering (VA/VE) = 价值分析与价值工程

## 定义

价值分析与价值工程（Value Analysis / Value Engineering, 简称 VA/VE）是一种通过系统性分析产品、服务或物流流程的功能与成本，旨在以最低的总成本持续实现必要功能的管理方法。在国际货运与供应链管理中，它常被用于优化包装、运输路线及仓储方案，从而在不降低服务质量的前提下实现降本增效。

## 详细说明

- 使用场景：主要应用于大宗货物物流规划、出口包装优化（如减少体积重量比）、海外仓储布局调整以及供应链整体方案设计阶段。
- 关键规则或数字：通常遵循“功能/成本”提高价值比的原则；在实操中，包装优化常以减少10%-30%的空运/海运运费（泡货压缩体积）为直接目标。
- 实务注意事项：在进行VA/VE改造时，必须充分评估货物在长途运输中的抗震、防潮及装卸安全要求，切不可为了单纯降低包装成本而导致货损率上升。

## 常见误区

- 误区一：认为 VA/VE 就是单纯的“砍预算”和压榨供应商价格。实际上，它是通过优化设计、改进工艺或重构流程来消除不必要的成本，实现买卖双方共赢。
- 误区二：只关注单环节运费节省。忽略了因包装改变或路线调整可能带来的装卸效率下降、海关查验风险或货损增加等隐性成本。

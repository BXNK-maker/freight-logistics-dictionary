> 📖 分类：**供应链管理** / 计划体系　｜　Forecast Value Added (FVA) = 预测增值分析

## 定义

Forecast Value Added (FVA，预测增值分析) 是一种用于评估供应链中不同预测步骤和环节对最终预测准确性实际贡献的方法。它通过对比“基础预测（如数学模型自动生成的基准）”与“各部门人工调整后预测”的误差，帮助企业判断哪些预测环节真正产生了增值，哪些环节反而引入了误差。

## 详细说明

- 使用场景：广泛应用于跨国货代、制造企业的全球供应链及库存规划中，特别是在销售、运营和财务（S&OP）协同预测时，用来评估人工干预是否有效。
- 关键规则或数字：计算核心是比较“调整前”与“调整后”的预测准确率（如绝对百分比误差 MAPE）。如果某环节的调整让误差变小，说明有正向 FVA；反之，若误差变大甚至持平，说明该环节的干预产生了负值，需取消该步骤以降低运营成本。
- 实务注意事项：在国际物流备货中，不要为了调整而调整。应定期通过 FVA 审计业务团队的表现，减少主观臆断对备货计划的干扰，从而优化海运整箱（FCL）或拼箱（LCL）的舱位和库存规划。

## 常见误区

- 认为人工干预越多，预测结果就一定越准：实际上，许多人工调整（如销售人员的主观乐观估计）往往会拉低预测准确率，产生负的 FVA。
- 将 FVA 等同于绩效考核工具：FVA 的初衷是优化流程和消除无效劳动，而非直接用于惩罚预测失误的员工。

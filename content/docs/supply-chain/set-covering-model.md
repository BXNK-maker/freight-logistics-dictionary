> 📖 分类：**供应链管理** / 网络设计　｜　Set Covering Model = 集合覆盖模型

## 定义
集合覆盖模型（Set Covering Model）是运筹学中的经典数学规划模型，在物流网络设计中用于确定最少数量的设施（如仓库、配送中心或中转站）选址，以确保所有需求点都在既定的服务半径或时间范围内。该模型的核心目标是在满足全部客户覆盖的前提下，实现固定建设成本或设施数量的最小化。

## 详细说明
- 使用场景：广泛应用于区域分拨中心（RDC）选址、快递末端网点布局、应急物流物资储备点规划，以及海运集装箱堆场（CY）的网络覆盖规划。
- 关键规则或数字：模型的核心约束是“全覆盖”，即每个需求点必须至少被一个设施所服务；服务半径通常以公里数（如50公里内）或运输时间（如2小时内）为硬性指标。
- 实务注意事项：在实际货代和供应链规划中，该模型较少单独使用，通常会与成本优化模型结合；由于未考虑设施容量限制，实操时需额外校验选定地点的吞吐能力，避免出现“有点无量”的过载情况。

## 常见误区
- 误认为集合覆盖模型会自动寻找总成本最低的方案：该模型关注的是“用最少设施实现100%覆盖”，并不直接将运输变动成本或土地购置成本纳入优化目标。
- 忽略容量约束：误以为只要模型选址通过，该仓库就能处理辖区内的所有货物，忽略了仓库的实际库容和装卸货台限制。

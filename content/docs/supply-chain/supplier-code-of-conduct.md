> 📖 分类：**供应链管理** / 合规可持续　｜　Supplier Code of Conduct = 供应商行为准则

## 定义
供应商行为准则（Supplier Code of Conduct）是企业制定的指导其供应链上下游合作伙伴在商业道德、劳工权益、环境保护、健康安全等方面行为规范的正式文件。在国际货运与物流领域，它是跨国货代公司及大型发货人评估和管理境外供应商、承运商合规性的核心契约标准。

## 详细说明
- 使用场景：广泛应用于跨国零售商、大型制造企业及头部物流服务商（如DHL、Maersk）的供应商准入审核（Vendor Audit）、年度合规审查以及ESG（环境、社会和公司治理）绩效评估中。
- 关键规则或数字：通常要求供应商承诺零容忍童工和强迫劳动、确保工作时间与薪酬符合当地法律、建立碳排放管理机制，并且在许多欧美进口国的合规审核中，通过率往往需要达到 85% 以上方可维持长期合作。
- 实务注意事项：随着欧盟《企业可持续尽职调查指令》（CSDDD）等法规的落地，物流企业不仅要自身合规，还必须将准则条款延伸至境外末端派送商和报关行，违规可能导致订单取消或巨额罚款。

## 常见误区
- 认为行为准则只是一纸空文，不需要在实际操作中核查承运商的资质。
- 混淆了“产品质量标准”与“供应商行为准则”，后者更侧重于劳工权益与碳减排等社会责任，而非单纯的货物规格。

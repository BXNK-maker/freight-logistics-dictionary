> 📖 分类：**物流数字化** / 数据标准　｜　Code 128 = 128码

## 定义
128码（Code 128）是一种高密度、可变长度的一维条形码标准，广泛应用于国际货运、仓储管理和供应链物流中。它能够高效编码包含数字、字母及特殊符号在内的完整 ASCII 字符集，是物流标签和运输单证上最常见的条码类型之一。

## 详细说明
- 使用场景：主要用于外箱标签、托盘标签（如 pallet label）、运输单据（如提单、运单）以及仓储货位管理，以便手持扫描枪或自动化分拣设备快速读取货物信息。
- 关键规则或数字：属于连续型条码，所有字符由 3 条条和 3 个空组成；包含 A、B、C 三种子集，其中 C 子集支持双数字压缩编码，极大提升了数字信息的存储效率和空间利用率。
- 实务注意事项：在打印物流标签时，必须确保条码周围有足够的“静区”（Quiet Zone），且打印分辨率不能过低，否则在运输途中经过多次转运摩擦后容易导致扫码失败。

## 定义

Remote ID（Remote Identification，远程识别）是指无人机或其他智能货运飞行器在飞行过程中，向外界实时广播其身份、位置、高度、速度及起飞点等关键飞行信息的电子技术。该技术旨在保障低空空域安全，便于航空管制部门和执法人员对无人机进行有效监控。

## 详细说明

- 使用场景：主要应用于低空物流配送、无人机末端派送、工业巡检以及城市空中交通（UAM）等场景。
- 关键规则或数字：根据中国民航局（CAAC）及美国联邦航空管理局（FAA）等监管机构的规定，大多数用于商业货运的无人机必须强制配备并激活 Remote ID，以满足空域监管和反恐防范的合规要求。
- 实务注意事项：货代与物流企业在跨境或本地使用无人机进行货物运输时，必须确保设备硬件和固件符合当地民航局的 Remote ID 标准，否则将面临航班禁飞、货物延误或高额罚款的风险。

## 常见误区

- 认为 Remote ID 只涉及军用或大型航空器：实际上，它对民用商业配送的小型无人机同样是强制合规要求。
- 误以为 Remote ID 会泄露操作员的商业机密：该技术广播的主要是飞行器的动态和注册信息，并不公开操作员的隐私数据。

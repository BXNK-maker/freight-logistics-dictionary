> 📖 分类：**物流数字化** / 可视化　｜　Machine Learning ETA = 机器学习到货预测

## 定义
Machine Learning ETA（机器学习到货预测，简称 ML ETA）是指货运物流系统利用人工智能和大数据算法，对货物实际到达时间进行动态预测的技术。它打破了传统静态计划的局限，通过持续分析历史数据与实时变量，为货代和外贸人提供更精准的节点预估。

## 详细说明
- 使用场景：广泛应用于海运、空运和跨境电商小包的全程追踪，特别是在遇到港口拥堵、极端天气或海关查验等突发情况时，用于修正预计到货时间。
- 关键规则或数字：算法通常每隔几小时自动刷新一次预测结果；在复杂的远洋航线中，相比传统船公司给出的固定计划（Schedule），ML ETA 的预测误差通常可缩小 30% 到 50% 左右。
- 实务注意事项：该技术高度依赖前端节点的实时数据录入（如 GPS 轨迹、EDI 报文），若基础数据滞后，预测准确率会大幅下降；同时，它只能作为决策参考，不可完全替代操作员对特殊突发事件的人工研判。

## 常见误区
- 认为机器学习 ETA 永远是百分之百准确的，忽略了突发港口罢工或不可抗力对算法的干扰。
- 误以为 ML ETA 可以替代传统的船期表（Schedule），实际上两者一个是动态预测，一个是基准计划，需结合使用。

> 📖 分类：**物流数字化** / 区块链应用　｜　EPCIS 2.0 = EPCIS 2.0事件标准

## 定义
EPCIS 2.0（Electronic Product Code Information Services 2.0，即电子产品代码信息服务 2.0 版本）是由 GS1 组织制定的全球供应链事件数据交换标准。它允许企业以结构化方式捕获和共享物品的流转轨迹，实现供应链全链路的可视化与可追溯。

## 详细说明
- 使用场景：广泛应用于冷链物流、医药溯源、跨境电商以及高端制造业，用于追踪货物在装卸、运输、仓储等环节的“Wherenow、When、What、Why”四个维度信息。
- 关键规则或数字：相较于旧版本，EPCIS 2.0 全面转向基于 JSON/JSON-LD 的网络友好型数据格式，支持 RESTful API 查询，并引入了物联网（IoT）传感器数据的无缝集成，便于处理温度、湿度等动态数据。
- 实务注意事项：货代和物流企业在对接系统时，需确保自身的仓储管理系统（WMS）和运输管理系统（TMS）能够支持 JSON 数据格式的解析与生成，以便向海外买家或品牌方实时推送标准化的物流事件节点。

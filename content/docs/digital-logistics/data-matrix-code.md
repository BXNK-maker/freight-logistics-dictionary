> 📖 分类：**物流数字化** / 数据标准　｜　Data Matrix Code = 数据矩阵码

## 定义
Data Matrix Code（数据矩阵码）是一种二维条码，由黑白相间的正方形或点阵组成，能够以高密度存储大量字母数字和二进制数据。在国际货运与物流中，它被广泛用于小件物品、电子元器件及医药冷链等场景的精准识别与全链路追溯。

## 详细说明
- 使用场景：主要应用于单件货物标签、SKU级条码标识、航空ULD（集装箱/集便板）标签以及制药和危险品物流的合规追溯，特别适合表面积有限但需要承载大量信息的微小部件。
- 关键规则或数字：Data Matrix采用独特的L形寻边模式（Finder Pattern），即使在标签破损、污损或面积仅剩20%的情况下，依然能够通过内置的错误纠正算法（ECC 200）被扫描设备完整读取。
- 实务注意事项：在海外仓储管理和跨境电商分拣中，打印Data Matrix标签时必须确保足够的对比度和分辨率，避免因热敏纸受潮或摩擦导致译码失败。

## 常见误区
- 误认为Data Matrix Code就是普通的QR Code：虽然两者都是二维条码，但Data Matrix的结构更紧凑，专为微小工业零件设计，且没有QR Code四周那三个标志性的定位方块。
- 误以为Data Matrix Code只能存储数字：实际上它支持ASCII字符、扩展ASCII及二进制数据，能够容纳完整的报关单号或产品批次信息。

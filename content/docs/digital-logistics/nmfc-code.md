## 定义

NMFC Code（全称为 National Motor Freight Classification Code，即美国货运分类代码）是美国国家公路货运协会（NMFTA）制定的一套标准化分类系统，用于对美国国内LTL（零担）公路运输货物进行归类。该代码根据货物的密度、责任、搬运难易程度和积载特性，将货物划分为18个不同的等级（Class），直接决定了运费的计收标准。

## 详细说明

- 使用场景：主要应用于美国本土的LTL（Less-Than-Truckload，零担）公路货运报价和计费环节。发货人或货代在向承运人（Carriers）预定LTL车位时，必须提供准确的NMFC Code。
- 关键规则或数字：NMFC体系将LTL货物划分为从 Class 50 到 Class 400 不等的18个等级。核心原则是“货越轻、体积越大、价值越高或越易碎，等级越高，每百磅运费（Fak/Rate）也越贵”；反之，密度大、包装坚固且不易损坏的重货则归入低等级，运费相对便宜。
- 实务注意事项：申报的NMFC Code必须与货物的实际物理属性（尺寸、重量、材质）严格相符。如果承运人在提货后重新测量发现不符，会导致“重新分级（Reclass）”并产生高额的罚款和运费差价补收。

## 常见误区

- 误区一：认为NMFC Code只是一串普通的参考编号，随便填一个不影响出货。实际上，它是承运人核算LTL运费的核心依据，填错会导致严重的运费争议和罚款。
- 误区二：认为同一类产品只有一个固定的NMFC Code。实际上，即使是同一种商品，如果包装方式改变（如打托盘与不打托盘）、密度发生变化，其适用的NMFC Code和运费等级也会随之改变。

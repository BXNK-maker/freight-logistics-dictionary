> 📖 分类：**物流数字化** / 数据标准　｜　UPC Code = 通用产品代码

## 定义
UPC Code（Universal Product Code，通用产品代码）是一种专为在物流和零售环节追踪商品而广泛使用的条形码标准。它由一串唯一的数字和黑白条纹组成，能够被光学扫描仪自动读取，从而实现商品信息的快速录入和识别。

## 详细说明
- 使用场景：主要应用于北美及全球进出口贸易中的零售商品包装、外箱标签及供应链管理，连接制造端、物流运输与零售终端。
- 关键规则或数字：标准的 UPC-A 码由 12 位数字组成，前半部分代表厂商识别代码，后半部分代表商品项目代码，最后一位为校验码。
- 实务注意事项：在国际货运中，外箱贴附的 UPC Code 必须清晰可读，避免在装卸和海运过程中因破损或污损导致扫描失败；发货前应与买家确认条码与出货清单完全一致。

## 常见误区
- 误区一：认为 UPC Code 等同于 SKU。实际上 UPC 是全球通用的标准条码，而 SKU 是企业内部自主管理的库存单位编码。
- 误区二：认为 UPC Code 只用于零售收银。在现代物流中，它同样是仓储分拣、库存盘点和供应链追溯的重要数据源。

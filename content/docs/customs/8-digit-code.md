> 📖 分类：**关务合规** / 归类规则　｜　8-digit Code = 八位编码

## 定义
8-digit Code（八位编码）通常指在国际贸易和海关申报中，基于协调制度（HS Code）细化至第八位的商品编码。它是海关对进出口货物进行精确分类、征收关税以及实施监管的核心数字代码。

## 详细说明
- 使用场景：广泛应用于进出口报关、原产地证申领、出口退税申报及国际货代制单环节。
- 关键规则或数字：前六位为国际通用的HS编码，第七、八位由各国海关根据本国的税收、贸易统计和监管需要自行增设，因此不同国家的后两位编码可能存在差异。
- 实务注意事项：订舱和制单时务必向发货人索取准确的8位编码，因为这直接决定了海关监管条件、检验检疫要求及正确的关税税率，填报错误会导致货物被海关扣留或产生罚款。

## 常见误区
- 认为全球的8位编码完全一致：实际上前6位国际通用，后2位因国家而异，出口前必须确认目的港的编码规则。
- 仅凭货名随意估算编码：商品归类具有极强的专业性，材质、用途和成分的微小差异都会导致8位编码完全不同。

> 📖 分类：**关务合规** / 知识产权保护　｜　IP Detention Security = 知识产权担保扣货

## 定义
知识产权担保扣货（英文通常简称为 IP Detention Security 或 IP-related Detention）是指海关或执法机构因怀疑进出口货物涉嫌侵犯知识产权（如商标、专利、版权）而对其实施扣押，但在符合特定条件时，允许收发货人提供相应的经济担保（如保证金或银行保函）将货物先行放行的海关监管措施。该机制旨在平衡知识产权权利人的保护与国际贸易的顺畅流转。

## 详细说明
- 使用场景：常见于品牌服饰、电子产品、汽车配件等高仿或易涉侵权风险货物的跨境运输中。当海关发现货物疑似侵权并收到权利人扣货申请时触发。
- 关键规则与数字：根据《知识产权海关保护条例》等相关法律，海关扣货后，权利人通常需在法定期限内（如中国海关为3个工作日内）向法院起诉或申请海关没收，并提供相当于货物等值的担保金；若需提前放行，收发货人则需向海关提交相当于货物价值100%甚至更高的担保金（Counter-security）以解除扣留。
- 实务注意事项：货代与外贸企业应严格审核客户资质，拒绝承运侵权“傍名牌”货物。一旦遭遇扣货，应第一时间联系专业海关律师，评估侵权风险并与权利人及海关协商担保放行事宜，以避免产生高昂的滞港费（Demurrage & Detention）。

## 常见误区
- 误区一：认为只要交了担保金，货物就一定能永久放行。实际上，担保放行只是暂时解除海关控制，后续仍需等待法院或海关的最终侵权裁决，若判定侵权，担保金将被没收并面临罚款。
- 误区二：认为海关扣货是承运人（船公司或货代）的责任。实际上，IP Detention Security 是海关的法定行政执法行为，货代无权干涉且不承担因扣货带来的商业违约责任，但有义务协助收发货人处理相关单证。

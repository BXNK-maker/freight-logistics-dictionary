> 📖 分类：**关务合规** / 归类规则　｜　10-digit Code = 十位编码

## 定义
10-digit Code（十位编码）通常指美国海关及边境保护局（CBP）在进口申报时要求使用的十位制商品编码，它是基于国际通用的《协调制度》（HS Code）前六位，并结合美国海关进出口统计分类进一步细化而成的法定申报代码。准确的十位编码是确保货物顺利清关、正确缴纳关税以及满足海关合规要求的基础。

## 详细说明
- 使用场景：主要用于海关进口申报（即 Importer Security Filing 或 7501 报关单），在货物抵达美国港口前必须由进口商或其代理人向海关提交。
- 关键规则：该编码的前六位与国际 HS Code 完全一致，第七、八位用于美国海关关税分类，第九、十位则用于统计和特定的管理需求。
- 实务注意事项：编码归类错误可能导致海关查验、清关延误、高额罚款甚至货物被扣；出口企业在发货前应与美国收货人或专业的报关行（Customs Broker）确认编码的准确性。

## 常见误区
- 误认为十位编码与中国出口的报关编码完全相同。实际上，中国出口通常使用8位或10位HS编码，而美国进口的10位编码（HTSUS）在后四位上与中国标准存在差异，不能直接照搬。
- 认为只要前六位国际通用的 HS Code 准确即可。在美国海关申报中，后四位的精确度同样至关重要，归类错误会直接引发合规风险。

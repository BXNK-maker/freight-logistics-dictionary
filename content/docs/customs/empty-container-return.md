> 📖 分类：**关务合规** / 报关流程　｜　Empty Container Return = 空箱归还申报

## 定义

Empty Container Return（简称 ECR，中文通常译为“空箱归还申报”）是指收货人或其代理人在进口货物拆箱卸货完毕后，通过船公司或码头的线上系统，申报将集装箱空箱按时、按指定地点归还的操作流程。它是国际海运物流中集装箱资产管理的重要环节，直接关系到用箱人是否会产生超期滞箱费。

## 详细说明

- 使用场景：适用于所有进口整箱（FCL）货物。在收货人完成卸货、清理箱体内部后，必须办理空箱归还申报，以便取得合法的还箱指引和进闸凭证。
- 关键规则：必须在船公司规定的“免费用箱期”（Free Time）内完成申报并实际还箱。若超时归还，将按自然日累加计算超期滞箱费（Demurrage & Detention）。部分码头要求必须凭电子申报成功后的 EIR（Equipment Interchange Receipt，设备交接单）才能进闸。
- 实务注意事项：
  - 还箱前必须彻底清除箱内残留的货物包装、木托盘及垃圾，保持箱况清洁，否则码头可能拒绝收箱并产生洗箱费。
  - 务必核对船公司指定的还箱堆场（Depot），错误还至非指定堆场不仅无法完成交还，还可能产生二次短途拖运费。

## 常见误区

- 误区一：认为只要把货物卸完，集装箱放在收货人仓库就万事大吉。实际上，未及时办理空箱归还申报并送回指定堆场，滞箱费会持续累积。
- 误区二：认为任何一个堆场都可以还箱。不同船公司的空箱指定还收堆场各不相同，未按指定地点还箱会导致交箱失败。

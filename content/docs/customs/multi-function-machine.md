> 📖 分类：**关务合规** / 归类规则　｜　Multi-function Machine = 多功能机器归类

## 定义
多功能机器归类（Multi-function Machine Classification）是指在国际贸易和海关申报中，对具有两种或以上明显不同功能的复合型机器（如既能打印又能扫描还能复印的一体机）进行商品编码（HS Code）归类的专业实务。这类机器通常由一个主导功能来决定其整体的归类归属。

## 详细说明
- 使用场景：广泛应用于现代办公设备、工业复合加工机械、智能终端设备等进出口报关环节。
- 关键规则或数字：根据《海关进出口税则》归类总规则（GIR）及相关类注、章注，多功能机器通常应按其“主要功能”进行归类；若无法确定主要功能，则按从后归类原则（最后税号优先原则）处理。
- 实务注意事项：报关前必须仔细查阅设备的说明书和技术参数，准确向海关申报各项核心功能；若归类错误可能导致海关退单、重新核税甚至因涉嫌伪报而产生行政处罚。

## 常见误区
- 误认为多功能机器可以随意选择其中一个简单的功能进行申报以获得更低的关税税率。
- 忽视技术规格书的重要性，仅凭外观形态对复合型机械进行归类。

> 📖 分类：**关务合规** / 归类规则　｜　Multi-function Machine = 多功能机器归类

## 定义
多功能机器归类（Multi-function Machine Classification）是指在海关进出口商品归类中，针对具备两种或以上不同功能的复合型机器（如既能打印又能扫描的一体机），根据其主导功能或特定归类原则将其归入单一税号的业务操作。它直接关系到货物的关税税率计算、监管条件适用以及报关单证的准确性。

## 详细说明
- 使用场景：主要应用于海关申报、商品预归类以及海关稽查环节，特别是进口高科技电子产品、办公自动化设备及工业复合加工机械时。
- 关键规则或数字：根据海关进出口税則归类总规则（尤其是规则三(三)），当机器无法通过主要功能确定归类时，应按从优归类原则或税号顺序在后原则处理，具体需参照协调制度（HS）注释及海关总署的相关行政裁定。
- 实务注意事项：货代和外贸企业在制单时，必须准确描述机器的各项技术参数、组件构成及实际工作原理，避免因功能申报不全导致海关质疑并重新归类，进而产生滞报金或行政处罚。

## 常见误区
- 误认为多功能机器可以随意选择税率最低的那个功能进行申报，忽视了海关关于“主导功能”的判定标准。
- 认为只要机器包含某项功能就必须单独申报所有附加零配件的税号，而忽略了整体归类的原则。

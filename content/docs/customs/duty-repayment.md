> 📖 分类：**清关**　｜　Duty Repayment = 关税退还

## 定义

关税退还（Duty Repayment）是指进口商或其报关代理在特定法定情形下，依法向海关申请退还已实际缴纳的全部或部分关税的行政与财务流程。这通常发生在海关多征税款、申报差错、或者进口货物因残损、规格不符而被退运或销毁的情况下，是保障纳税人合法权益的重要救济机制。

## 详细说明

- **常见使用场景**：
  - 申报差错：因商品编码（HS Code）归类错误适用偏高税率、申报价值（Customs Value）计算失误或币种选错导致溢缴关税。
  - 货物不符：到港货物存在质量缺陷或与外贸合同严重不符，进口商选择拒收并作退运（Re-export）或海关监管下销毁处理。
  - 原产地事后补正：货物通关时未能及时提交优惠原产地证书，在后续规定期限内补交后申请享受协议优惠税率并退还差额。
- **关键规则与数字**：
  - 申请时效：各国海关均有时限规定。例如英国和欧盟海关通常规定，因多征税款申请退税的时效为缴纳之日起 3 年内；因货物残损或拒收申请退款通常为 1 年内；中国海关规定纳税义务人自缴纳税款之日起 1 年内可申请退还多征税款。
- **实务注意事项**：
  - 举证责任在申请人：必须提供完整的证据链（如原进口报关单、付款水单、质检报告、退运提单等）。
  - 税费联动：关税退还通常会伴随进口增值税（Import VAT）或消费税的调整，需注意与财务端进项税抵扣状态保持同步，避免税务违规。

## 中英对照

| 英文表达 | 中文表达 | 业务说明 |
| :--- | :--- | :--- |
| Duty Repayment | 关税退还 | 特指海关将已缴纳的全部或部分关税退还给进口商 |
| Duty Remission | 关税免征 / 关税豁免 | 海关在税款尚未实际缴纳前作出的免除征收决定 |
| Duty Drawback | 关税退税 / 出口退税 | 特指原材料或零部件进口完税后，加工复出口时的退税制度 |
| Overpaid Customs Duty | 多缴关税 / 溢缴关税 | 申请退还的最常见原因，因估价、归类或汇率错误所致 |

## 常见误区

- **混淆 Duty Repayment 与 Duty Drawback**：前者侧重于“纠错与补偿”（如溢缴、退运拒收退税），后者通常是促进出口的贸易便利政策（加工后再出口退税），二者申请条件与适用法条完全不同。
- **误以为任何退运都能直接退关税**：如果进口货物已被投入商业使用、转卖或在境内加工，即使后续因质量问题退运，海关通常也不再批准关税退还，必须严格保持货物未拆改或经海关验核符合退款标准。

> 📖 分类：**关务合规** / 估价规则　｜　Deductive Value Method = 扣减价格法

## 定义

扣减价格法（Deductive Value Method）是海关估价方法之一，指以进口货物在境内第一销售环节的单价为基础，扣除境内发生的合理费用来确定进口货物完税价格的方法。当海关无法使用成交价格法时，通常会优先考虑这种方法。

## 详细说明

- 使用场景：当进口货物没有成交价格，或者成交价格不符合海关估价规定时，海关会依次使用其他估价方法，扣减价格法是其中的重要法定方法之一。
- 关键规则或数字：计算起点是货物进口后在境内销售的第一批相同或类似货物在最迟销售日的单价。需要扣除的费用主要包括：境内运保费、进口环节税费、境内销售佣金或利润及一般费用、加工增值等。
- 实务注意事项：外贸企业和货代人员需要提供准确的境内销售记录及相关成本发票。如果货物经过进一步加工后再销售，海关在扣减时会扣除加工增值成本，这需要详细的账册支持。

## 常见误区

- 误以为扣减价格法就是简单的“倒扣利润”，实际上它需要扣除一系列复杂的境内合规费用和税收。
- 认为该方法可以随意使用，忽视了海关估价方法适用的法定顺序。

## 定义

Data Media Value（数据载体价值，简称DMV）是指在国际贸易和货运中，用于存储软件、图纸、音视频或各类数字化数据及程序的物理载体（如硬盘、U盘、磁带、光盘等）本身所包含的物质价值，而非其中存储的数据内容本身的价值。在海关申报时，这通常是决定关税征收基础的重要概念。

## 详细说明

- 使用场景：主要适用于数字化资产、定制化软件、研发图纸或影视母盘等以物理介质传输的报关环节。
- 关键规则或数字：根据国际海关估价惯例，海关在计征关税时，通常只对“数据载体价值”（即空白介质本身的成本加运费）征税，而不得对载体上存储的数据本身的商业价值重复征税，前提是数据价值与载体价值在商业发票中须明确分开列示。
- 实务注意事项：发货人和货代在制作商业发票时，必须将“空白载体成本”与“知识产权/数据内容价值”分项列出。如果发票仅显示一个包含高额数据价值的总价且未作区分，海关可能会直接按总价征收高额关税。

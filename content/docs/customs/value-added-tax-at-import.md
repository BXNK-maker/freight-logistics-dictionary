> 📖 分类：**关务合规** / 关税制度　｜　Value Added Tax at Import = 进口增值税

## 定义
进口增值税（Value Added Tax at Import，简称 Import VAT）是指货物在进口通关时，海关根据国家税法对进口货物征收的一种增值税。它是货物进入进口国境内流通环节前必须缴纳的国内税收，通常以货物的完税价格加上关税及其他进口环节税费为基数来计算。

## 详细说明
- 使用场景：适用于所有以一般贸易或其他应税方式进口货物的国际物流与供应链业务，通常由进口商或其指定的报关行负责缴纳。
- 关键规则与计算：计算公式通常为：进口增值税 = (CIF 货价 + 关税 + 其他进口税费) × 当地法定增值税税率。例如，欧盟各国的进口 VAT 税率因国而异，一般在 17% 到 27% 之间。
- 实务注意事项：进口增值税不同于关税（Customs Duty），关税属于成本，而符合资质的企业在缴纳进口 VAT 后，通常可以在后续的增值税申报中作为进项税额（Input VAT）进行抵扣或申请退税，因此它主要影响企业的现金流而非最终成本。

## 常见误区
- 误认为进口增值税就是关税：关税是货物进口的成本，而进口增值税属于可抵扣的流转税，两者在财务处理和性质上完全不同。
- 误认为所有进口商都能自动退税：只有具备当地税号（VAT Number）并以合法进口商身份清关的企业，才能将进口 VAT 作为进项税额进行抵扣。

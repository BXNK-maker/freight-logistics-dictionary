> 📖 分类：**关务合规** / 估价规则　｜　Test Values = 测试价格

## 定义
Test Values（测试价格，海关估价中的测试价值）是指海关在评估关联方交易的进口货物完税价格时，允许进口商用来证明该交易价格未受买卖双方特殊关系影响的一种特定估价参考标准。它通常是海关先前已接受过的、同类或相似货物的成交价格。

## 详细说明
- 使用场景：当买卖双方存在关联关系（如母子公司），且海关怀疑这种关系影响了进口货物的申报价格时，进口商可主动向海关提交Test Values作为证据，以维护申报的成交价格。
- 关键规则或数字：作为测试价格的参照物必须是近期（通常为同期或前后45天内）向中国境内出口的相同或类似货物的成交价格。同时，该测试价格必须已经过海关审核确认，且其各项扣除或调整因素必须符合海关规定。
- 实务注意事项：提交测试价格并不自动免除海关的审查责任。进口商必须提供充分的商业文件和财务数据，证明申报价格在结构和利润率上与作为测试价格的参照标准高度一致，否则海关有权拒绝并改用其他方法重新估价。

## 常见误区
- 认为只要找到一个相似的进口价格就可以直接作为测试价格，忽视了海关对“近期”和“相同或类似货物”的时效与匹配要求。
- 误以为测试价格是海关强制要求的标准程序，实际上这是由进口商为抗辩海关质疑而主动举证的辅助手段。

## 定义

Customs Value for VAT（增值税完税价格）是指海关在进口环节计算增值税时所依据的货物法定价值基础。它是确定进口货物应缴纳增值税额的核心基数，直接影响企业的进口税务成本。

## 详细说明

- 使用场景：主要应用于跨境贸易进口清关环节，特别是目的地为欧盟等实行增值税制度国家和地区的货物申报。
- 关键规则：其计算基础通常不仅仅是货物的FOB或CIF货值，国际运费、保险费以及在特定情况下产生的特许权使用费等，都需要依法计入完税价格中。
- 实务注意事项：计算公式一般为：完税价格 = 货价 + 运费 + 保费 + 关税。报关时必须确保各项费用的发票和凭证真实准确，任何瞒报运费或遗漏费用的行为都可能面临海关稽查、补税及罚款风险。

## 常见误区

- 认为完税价格就是商业发票上的货值：忽略了运费、保险费等附加费用必须合并计入完税价格的规定。
- 混淆关税完税价格与增值税完税价格：虽然两者的计算基础高度重合，但在某些特定税率减免或附加费用的处理上可能存在细微差异。

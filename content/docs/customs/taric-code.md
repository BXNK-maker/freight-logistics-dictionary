> 📖 分类：**关务合规** / 归类规则　｜　TARIC Code = 欧盟综合税则编码

## 定义

TARIC Code（Integrated Tariff of the European Communities，即欧盟综合税则编码）是欧盟用于管理海关关税、进出口统计以及商业政策的多语言综合数据库编码。它是在国际通用的8位数HS Code基础上，精确扩展至10位甚至更多的数字，用于明确特定商品在欧盟境内的具体关税税率及贸易管制要求。

## 详细说明

- 使用场景：主要用于向欧盟27个成员国申报进口或出口货物时确定准确的关税税率、增值税率、反倾销税、配额限制及进口许可证要求。
- 关键规则或数字：该编码通常由10位数字组成（前6位为HS Code，第7-8位为欧盟联合税则CN Code，第9-10位为TARIC特定附加码）；在某些涉及化学品或特定管制措施时，还可能需要附加4位的TARIC附加码。
- 实务注意事项：由于欧盟各成员国的增值税（VAT）和部分本地税费政策可能存在差异，且TARIC税率会根据欧盟法规频繁更新，货代和外贸人员必须在每次出货前通过欧盟官方TAXUD网站实时查询最新的编码状态，以免因归类错误导致货物清关延误或产生巨额罚款。

## 常见误区

- 认为TARIC Code就是HS Code：实际上HS Code仅全球通用前6位，而TARIC Code是欧盟在此基础上面向本土市场延伸出的10位精准税则。
- 编码一成不变：TARIC Code和相关税率会根据欧盟委员会的最新指令进行动态调整，直接套用去年的旧编码极易导致申报错误。

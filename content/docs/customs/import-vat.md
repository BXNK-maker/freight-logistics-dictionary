> 📖 分类：**清关**　｜　Import VAT = 进口环节增值税

## 定义

Import VAT（进口环节增值税）是指货物在进口通关时，海关代表国家税务机关对进口货物征收的增值税。它是国际贸易中除关税外最常见的税费之一，通常以货物的完税价格加上关税及其他进口税费为基数计算。


## 详细说明

- 使用场景：适用于绝大多数进口到实行增值税国家（如欧盟各成员国、中国等）的商业货物清关环节，海关放行前必须缴清或提供相应的税务担保。
- 关键规则：以欧盟为例，标准 Import VAT 通常为货值的 19%-27% 不等；在中国，进口货物增值税标准税率一般为 13%（部分农副产品等为 9%）。计算公式通常为：应纳税额 =（关税完税价格 + 关税 + 消费税）× 增值税税率。
- 实务注意事项：一般纳税人企业在支付 Import VAT 后，通常可以在后续的增值税申报中作为进项税额（Input VAT）进行抵扣，因此对企业而言这往往是现金流问题而非最终成本；部分国家（如荷兰、比利时）允许申请延期纳税（Postponed VAT Accounting），从而优化企业的资金占用。

## 常见误区

- 误区一：认为 Import VAT 是货代收取的费用。实际上，这是海关征收的国家税费，货代通常只是垫付或代办清关，最终税款属于国家税务范畴。
- 误区二：认为进口增值税和关税是一回事。关税是进口货物的成本，而 Import VAT 属于可抵扣税费，两者在财务处理和性质上有本质区别。

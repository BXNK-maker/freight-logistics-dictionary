## 定义
军事最终用户规则（Military End User Rule，简称MEU Rule）是指主要由美国商务部工业与安全局（BIS）实施的一项出口管制法规。该规则旨在防止特定国家的军方或军事组织获取可能增强其军事能力的民用敏感物资和技术。

## 详细说明
- 使用场景：广泛应用于出口美国原产的商业级

> 📖 分类：**关务合规** / 归类规则　｜　Most Specific Description = 最具体描述

## 定义

Most Specific Description（最具体描述）是指在国际货物运输和海关申报中，对货物品名进行精确、无歧义且深入到具体材质、用途或型号的描述。该原则要求申报信息必须能够明确区分该货物与其他同类货物，避免使用过于宽泛的统称。

## 详细说明

- 使用场景：主要应用于进出口海关预归类、提单（B/L）制作、舱单申报以及危险品和锂电池等特殊货物的合规性审查。
- 关键规则：海关及监管机构严格禁止使用如 "machinery"（机械）、"parts"（零件）、"chemicals"（化学品）等模糊字眼。必须细化至具体名称、功能及成分，例如将 "auto parts" 改为 "steel brake pads for passenger cars"（乘用车用钢制刹车片）。
- 实务注意事项：申报不符合 Most Specific Description 要求极易导致海关系统布控查验、扣货甚至产生海关罚款。货代在审核客户提供的箱单发票时，若发现品名过于笼统，务必要求发货人补充详细规格，以确保顺利通关。

## 常见误区

- 误以为只要提供了 HS Code，货物品名怎么写都无所谓。实际上，海关审核时品名描述与 HS Code 必须高度吻合且相互印证。
- 认为简化品名可以保护商业机密。在国际物流合规中，隐瞒具体品名或使用笼统描述属于违规行为，将直接承担法律责任。

> 📖 分类：**关务合规** / 归类规则　｜　Set Classification = 成套货品归类

## 定义

成套货品归类（Set Classification）是指海关根据《进出口税则》的归类总规则，对为了满足某种特定需要而组合在一起的多件不同物品，作为一个整体进行商品编码（HS Code）归类的海关监管行为。它直接决定了货物的关税税率、监管条件及原产地判定标准，是国际贸易合规中的重要环节。

## 详细说明

- 使用场景：主要适用于企业进口散装成套设备、零售包装的礼品套装、配套销售的工具组合以及多功能一体化商品。
- 关键规则或数字：根据海关归类总规则（如《协调制度》GIR 3(b)），成套货品必须满足三个核心条件：一是必须由至少两件不同物品组成；二是为满足特定需要或完成某项特定活动而组合；三是经包装适合直接供应给用户，且无需重新包装。
- 实务注意事项：若套件中包含非成套目的的独立高价值零部件，海关可能要求分拆申报；报关时必须准确提供成套货品中各主要组件的品名、材质及各自价值占比，避免因归类错误导致海关稽查或补税罚款。

## 常见误区

- 误认为只要把几种商品装在同一个箱子里就属于成套货品，忽视了必须“为满足特定需要而组合”的功能关联性要求。
- 混淆了零售包装的组合商品与工业生产用的散装零配件集合，导致适用错误的归类规则。

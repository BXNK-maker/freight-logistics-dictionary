> 📖 分类：**关务合规** / 归类规则　｜　Set Classification = 成套货品归类

## 定义
成套货品归类（Set Classification）是指海关根据《进出口税则》的归类总规则，对由两件及以上独立包装、组合在一起用于满足某种特定需求或完成特定功能的成套物品，进行作为一个整体货号申报和归类的海关执法行为。这是一种特殊的商品归类方法，直接影响关税税率的确定。

## 详细说明
- 使用场景：主要应用于散装或组合销售的礼品套装、工具箱、成套机械设备备件、医疗急救包及电商打包组合商品等外贸报关环节。
- 关键规则或数字：根据《协调制度》（HS）归类总规则三（款）（GIR 3(b)），成套货品必须满足三个硬性条件：一是必须由至少两件不同类目的商品组成；二是包装在一起且为了满足特定需要或进行某项特定活动（如工具箱用于维修）；三是其包装形式适合直接供应给用户而无需重新包装（如零售包装）。
- 实务注意事项：货代与外贸企业在制单时必须准确识别成套货品。如果套件中包含核心高价值部件，海关可能会要求拆分申报（按各自税号归类），因此企业应提前向海关申请预归类或提供完整的品名、材质及用途说明，避免因归类不符导致清关延误或行政处罚。

## 常见误区
- 误区一：只要把几种不同的商品装在一个箱子里，就自动构成了法律意义上的“成套货品”。实际上，如果这些商品组合不符合“为了满足特定需要或进行某项特定活动”的条件，海关会要求分别按各自的HS编码申报。
- 误区二：成套货品的税率一定比单个商品低。实际上，成套货品通常需按照构成其“基本特征”的主要部件归类纳税，有时反而会适用较高税率的独立税号。

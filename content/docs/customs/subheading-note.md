## 定义

Subheading Note（子目注释）是国际海关税则中专门用来限定和解释某一个或某一组子目（Subheading）适用范围的文字说明。它具有法律约束力，是准确进行进出口商品归类（HS Code Classification）不可或缺的依据。

## 详细说明

- 使用场景：当货代或外贸企业在《协调制度》（HS）编码表中查询到具体四位数税目下的六位数子目时，如果该子目上方或章、类说明中附有 Subheading Note，则必须对照此注释来确认货物是否满足特定条件。
- 关键规则或数字：子目注释通常遵循《协调制度》的解释规则（GIR）。若无特殊说明，类注释和章注释的效力优先于子目注释，但子目注释仅适用于本章特定子目，不能跨章通用。
- 实务注意事项：在归类时，切勿仅凭商品名称直接套用子目，必须仔细阅读相关的子目注释，防止因忽略特定材质、技术规格或成分含量的界定而导致归类错误，进而引发海关稽查或补税风险。

## 常见误区

- 误认为子目注释只是一般参考意见，不具备强制执行的法律效力。
- 混淆章注释（Chapter Note）与子目注释（Subheading Note）的适用层级，导致将全局规则错用于局部子目。

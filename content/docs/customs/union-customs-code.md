> 📖 分类：**清关**　｜　Union Customs Code = 欧盟海关法典

## 定义
欧盟海关法典（Union Customs Code，简称 UCC）是欧盟现代海关制度的核心法律框架，于2016年5月1日正式生效。它旨在统一欧盟成员国之间的海关规则，全面推行海关作业无纸化和数字化，从而简化海关程序并保障供应链安全。

## 详细说明
- 使用场景：适用于所有进出欧盟关境的货物运输、仓储、申报及转关业务，是货代和外贸企业开展对欧贸易必须遵循的最高海关法规。
- 关键规则与特点：UCC 彻底淘汰了纸质报关，强制要求所有海关沟通必须通过电子数据交换进行；强化了“集中清关”概念，允许企业在一个成员国办理整个欧盟的进口海关手续；对 AEO（经认证的经营者）资质给予更多通关便利。
- 实务注意事项：货代在安排欧盟转关时，必须准确使用新系统（如 NCTS 5期）并确保电子舱单数据与实际货物完全一致，任何申报延迟或数据不符都可能导致欧盟海关的高额罚款或货物滞港。

## 常见误区
- 误区一：认为在德国清关的货物只能在德国境内销售，不能转运到其他欧盟国家。实际上，借助 UCC 的自由流通原则和过境制度，货物在欧盟一国清关后即可在成员国间自由流通。
- 误区二：认为 UCC 是各成员国自己制定的地方性法规。实际上它是欧盟层面的统一立法，直接适用于所有欧盟成员国，具有最高法律效力。

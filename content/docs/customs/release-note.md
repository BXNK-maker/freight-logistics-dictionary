> 📖 分类：**关务合规** / 报关流程　｜　Release Note = 放行通知书

## 定义

Release Note（放行通知书）是海关、码头或仓库在完成货物查验、税费缴纳及相关单证审核后，签发给货方或代理人提取、转运货物的正式凭证。它是货物监管状态由“受控”转为“放行”的关键法律文书，也是物流操作中不可或缺的交接依据。

## 详细说明

- 使用场景：主要用于进口货物清关后的提货环节，常见于海关监管仓库、港口码头及保税区。当货代或车队凭此单据到现场时，场站方才允许安排装车和出闸。
- 关键规则：放行通知书通常有严格的有效期限制，收货人或其代理人必须在规定时间内完成提货，否则可能产生超期滞箱费、仓储费或面临重新报关的风险。
- 实务注意事项：在无纸化通关环境下，许多口岸已将纸质放行条转化为电子放行信息（如电子放行条）。操作人员必须仔细核对系统中的放行状态、提单号、箱号等核心数据，确保万无一失后再派车。

## 常见误区

- 误以为拿到Release Note就可以直接向船公司提吉箱或提货，忽略了还需要同时办理换单和支付码头费用的前置步骤。
- 将Release Note与Delivery Order（提货单）混为一谈，前者侧重于海关或监管部门的合规放行，后者侧重于承运人或其代理人的物权交接。

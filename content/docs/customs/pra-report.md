> 📖 分类：**关务合规** / 检验检疫　｜　PRA Report = 风险评估报告

## 定义

PRA Report 的英文全称为 Pre-Receiving Analysis Report，中文通常译为“风险评估报告”或“预收货风险评估报告”。它是航运和物流领域中，针对特殊货物（如危险品、超限货或敏感货物）在装运前进行的一项安全与合规性评估文件。

## 详细说明

- 使用场景：主要用于危险品海运拼箱（LCL）、特种柜（OOG）以及部分对港口接卸能力有严格要求的特殊散杂货操作中。当货代向船公司或码头提交危险品申请时，常被要求出具该报告。
- 关键规则与数字：船公司或码头会根据货物的联合国编号（UN Number）、闪点、包装类别（Packing Group）以及港口的安全法规进行审核。通常需要在船舶截单日前（CY Cut-off）提前数个工作日提交，以留出审核时间。
- 实务注意事项：若货物成分复杂或 MSDS（化学品安全技术说明书）信息不全，极易导致 PRA Report 审核被拒或延误，进而产生舱位费、滞港费或改单费，操作人员务必提前核对货物的精确属性。

## 常见误区

- 误认为 PRA Report 可以替代危险品申报单：实际上，PRA 只是码头或船公司在接收货物前的风险评估文件，不能代替正式的危险品海事申报。
- 认为所有普通普货都需要做 PRA：只有当货物被船公司或码头识别为潜在高风险、性质不明或属于特定敏感航线的特殊货物时，才需要进行此项评估。

> 📖 分类：**关务合规** / 欧美关务　｜　Import Control System 2 = 欧盟进口控制系统2

## 定义

Import Control System 2（简称 ICS2，中文通常译为欧盟进口控制系统2）是欧盟实施的全新海关预先电子货物信息系统。该系统旨在通过在货物抵达欧盟边境之前收集并分析所有入境货物的安全和安保数据，全面提升欧盟供应链的安全防护水平。

## 详细说明

- 使用场景：适用于所有通过海运、空运、公路及铁路运输，进入或途经欧盟（含北爱尔兰、挪威和瑞士）的所有货物。无论货物最终目的地是否为欧盟，只要航班或船舶经停欧盟，或在欧盟转运，均需进行申报。
- 关键规则或数字：ICS2 采取分阶段逐步推进（Release 1、2、3）的上线策略。根据运输方式的不同，承运人或货代必须在严格规定的截止时间（如空运短途/长途、海运集装箱的装载前）向海关提交完整的入境总申报单（ENS）数据。
- 实务注意事项：货代和外贸企业必须在货物起运前，向欧盟海关提供精确的货物编码（HS Code）、详尽的货物描述以及买卖双方的 EORI 号码。任何数据缺失或模糊都可能导致货物在起运港被拒绝装载，或在欧盟口岸面临查验和延误。

## 相关术语

## 常见误区

- 误区一：认为 ICS2 仅适用于目的地为欧盟的货物。实际上，所有过境欧盟或由欧盟进行中转的航班及船舶承运货物同样必须进行申报。
- 误区二：认为申报可以由海外收货人单独完成。在实际操作中，通常需要由承运人或受托货代在起运前提交前置的 ENS 数据。

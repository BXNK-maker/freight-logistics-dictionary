> 📖 分类：**关务合规** / 配额管理　｜　Tariff-rate Quota Import License = 关税配额进口许可证

## 定义
关税配额进口许可证（Tariff-rate Quota Import License，简称 TRQ Import License）是一种针对特定进口商品实施关税配额管理的贸易管制证件。持证人在配额总量和规定期限内进口相关货物时，可享受较低的配额内关税税率，超出部分则需缴纳较高的配额外关税。

## 详细说明
- 使用场景：主要适用于农产品、化肥等涉及国家安全、国计民生或国内产业保护的重要大宗商品进口申报。
- 关键规则：配额通常由国家主管部门（如商务部）分配给特定的最终用户或贸易商，许可证实行“一证一批”或“一次使用”制，且有严格的有效期限，一般当年有效，过期作废。
- 实务注意事项：货代和外贸人员在接单时必须严格审核收发货人是否具备相应的配额资格，并在舱单传输和报关前核对许可证上的商品编码（HS Code）、数量及贸易国别，确保与实际进口货物完全一致，避免因单证不符导致货物被海关扣留或面临高额惩罚性关税。

## 常见误区
- 误认为有了许可证就可以无限量进口：实际上，许可证仅代表在配额数量内享受低税率，超出配额虽然仍可进口，但需要承担极高的配额外关税。
- 将关税配额许可证与普通自动进口许可证混淆：前者直接关系到税率的高低和数量限制，管理极其严格；后者主要用于统计监测，申领相对宽松。

> 📖 分类：**清关**　｜　Transaction Value Method = 成交价格法

## 定义
成交价格法（Transaction Value Method）是海关估价中最核心、最优先使用的方法，是指以进口货物在实际买卖中向卖方支付或应当支付的价格为基础来审查确定进出口货物完税价格的方法。在绝大多数国际贸易进出口申报中，只要符合特定条件，海关都会默认并优先采用此方法来计算关税和增值税。

## 详细说明
- 使用场景：适用于绝大多数常规的买卖贸易，特别是买卖双方无特殊关系，或者虽有特殊关系但未对成交价格产生影响的进出口商业交易。
- 关键规则或数字：采用成交价格法时，卖方支付的价格通常需要进行调整。通常需要将运抵我国境内输入地点起卸前的运输费、保险费计入完税价格；而如果购货佣金、境内建设或安装费用已包含在总价中，则可以扣除。
- 实务注意事项：外贸与货代从业人员在做海关申报（Customs Declaration）时，必须确保发票（Commercial Invoice）金额真实、完整。若海关对申报价格产生合理怀疑，要求提供价格质疑资料时，企业必须举证证明成交价格的真实性，否则海关有权拒绝使用该方法并改用其他估价方法。

## 常见误区
- 误区一：认为只要有合同和发票，海关就必须无条件接受成交价格。实际上，如果买卖双方存在特殊关系影响了价格，或者申报价格明显低于市场公允水平，海关会拒绝该方法。
- 误区二：将成交价格等同于最终到岸价。成交价格是基于合同的货价，完税价格还需要在此基础上加上起卸前的运费和保险费等相关费用。

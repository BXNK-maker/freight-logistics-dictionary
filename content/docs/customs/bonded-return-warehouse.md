> 📖 分类：**关务合规** / 跨境电商　｜　Bonded Return Warehouse = 保税退货仓

## 定义

保税退货仓（Bonded Return Warehouse）是指专门用于存放、处理和重新包装跨境电商出口海外退货商品的特殊海关监管场所。它依托保税政策，允许境外退货商品免税或暂缓纳税进入海关特殊监管区域进行检测、维修、退运或重新上架销售。

## 详细说明

- 使用场景：主要应用于跨境电商出口业务（如 Amazon、AliExpress 等平台卖家），用于集中处理海外买家因尺码不合、质量问题或不喜欢而产生的退货。
- 关键规则或数字：根据中国海关相关规定，退入保税仓库的商品在海关监管年限内可享受“一线放行、区内暂存”政策；若商品需销毁或退运出境，可按规定免征关税和进口环节增值税。
- 实务注意事项：操作时必须严格做到账册对应，确保退货商品的条形码、海关备案信息与原出口报关单据一致，严禁未备案的普通货物与保税退货货物混放。

## 常见误区

- 误区一：认为所有海外退货都可以直接退回国内普通仓库。实际上，享受保税政策的退货商品必须进入海关批准的特定保税监管场所，否则将面临补缴关税和罚款的风险。
- 误区二：混淆保税退货仓与出口监管仓。保税退货仓针对的是境外退回的货物，而出口监管仓针对的是等待出口的货物，两者在海关监管程序和账册管理上完全不同。

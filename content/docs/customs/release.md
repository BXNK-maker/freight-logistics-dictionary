> 📖 分类：**清关**　｜　Release = 海关放行

## 定义

Release（海关放行）是指货物在进出口申报后，海关经过审核、查验或征税等环节，确认符合法律法规，准许货物提离海关监管区域的行政许可行为。它是货物完成清关手续的核心标志，意味着收发货人可以合法对货物进行后续的提取、转运或配送。

## 详细说明

- 使用场景：适用于一般贸易、保税物流、跨境电商等所有进出口海关监管货物的物流节点。
- 关键规则或数字：
  - 进口放行：通常在海关系统显示 "Release" 或 "Customs Released" 后，码头或仓库才允许提货。
  - 放行时效：常规报关单若无查验，通常在申报后数小时内放行；若遇海关查验（Inspection），则需在查验完毕并确认无误后方能获得 Release。
- 实务注意事项：
  - 务必核对放行状态与设备交接单（EIR）、提货单（Delivery Order）是否一致，避免盲目安排车队提柜导致空跑。
  - 部分特殊货物（如危化品、冷链）即使海关放行，还需取得港区或海事部门的二次放行指令方可作业。

## 常见误区

- 误区一：认为海关放行等于船公司放货。海关放行（Customs Release）是政府监管行为，而船公司放货（Cargo Release / D/O）是物权交接行为，两者必须同时满足才能提货。
- 误区二：只要系统显示申报成功就可以安排提货。申报成功仅代表数据已提交，必须取得海关明确的 Release 状态后才能提货，否则属于违规拉柜。

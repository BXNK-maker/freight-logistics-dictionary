> 📖 分类：**关务合规** / 归类规则　｜　13-digit Code = 十三位编码

## 定义
13-digit Code（十三位编码）通常是指国际贸易与物流中，用于精确标识特定货物、单据或企业身份的13位数字组合。在现代供应链管理中，它常见于海关商品编码、特定国家的电子舱单申报系统或条形码追踪体系中。

## 详细说明
- 使用场景：主要用于进出口报关时的商品归类（如某些特定海关的扩展编码）、供应链节点的货物条形码扫描，以及特定国际航线或目的港的电子舱单数据传输。
- 关键规则或数字：该编码严格由13位阿拉伯数字组成，每一位或每一段数字通常代表特定的分类层级、产地、属性或校验位，不得随意增减位数。
- 实务注意事项：在录入海关系统或货代管理系统时，必须确保13位数字完整无误，漏输、错输或多输会导致报关受阻、货物被海关扣留或系统无法识别条形码。

## 常见误区
- 误认为所有国家的HS Code都是13位：实际上世界海关组织的HS编码通用标准为前6位，各国家和地区会根据自身需要延伸至8位、10位或13位，并非全球统一为13位。
- 混淆内部编号与法定编码：将仓库内部使用的13位货品流水号当作法定海关编码使用，导致报关单货名与编码不符。

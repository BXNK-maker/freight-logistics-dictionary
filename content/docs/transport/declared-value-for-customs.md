> 📖 分类：**运输** / 空运单证　｜　Declared Value for Customs = 报关声明价值

## 定义
报关声明价值（Declared Value for Customs）是指进出口货物收发货人或其代理人向海关申报的、用于计算关税和环节税的货物真实完税价格。它是海关征收关税、增值税以及其他税费的重要法定依据，通常基于货物的实际交易价格确定。

## 详细说明
- 使用场景：适用于所有进出口货物的海关正式申报环节，无论是海运、空运还是陆运跨境贸易，都必须向海关如实提供该数值。
- 关键规则：该价值通常对应国际贸易术语（如 FOB、CIF）中的成交价格，必须包含货物运抵我国境内输入地点起卸前的运费和保险费（CIF 模式），若为 FOB 则需另外加上运保费进行申报。
- 实务注意事项：申报价值必须真实、准确，并与商业发票、合同、提单等单证保持一致。若故意低报、瞒报价格以逃避关税，将面临海关的行政处罚甚至刑事追究。

## 常见误区
- 误区一：认为报关声明价值可以随意填写。实际上，它必须有真实的购销合同和商业发票支撑，海关有权对明显不合理的申报价格进行质疑和估价。
- 误区二：将“报关声明价值”与“运输声明价值”混淆。前者是给海关交税用的，后者是给承运人（如航空公司）确定最高赔偿责任限额用的，两者金额可以不一致。

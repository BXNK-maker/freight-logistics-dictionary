> 📖 分类：**运输** / 铁路设施　｜　Train Path Request = 运行线申请

## 定义
Train Path Request（中文：运行线申请）是指铁路货运代理人或承运人向铁路基础设施管理机构（如铁路局）提交的，为其拟开行的货运列车在特定铁路线路上申请预留通行时间窗口和运行路径的正式请求。它是国际铁路联运和中欧班列操作中至关重要的前置环节。

## 详细说明
- 使用场景：适用于中欧班列、中亚班列等跨国铁路集装箱运输，以及国内铁海联运和点对点整车货运的订舱与计划申报阶段。
- 关键规则或数字：运行线通常按年度、季度或月度进行规划与分配；国际联运的运行线申请需要跨国铁路公司（如中国铁路与沿线国家铁路局）进行跨境时刻表对齐与技术核对。
- 实务注意事项：货代必须在列车预计发车前数周甚至数月提交申请，一旦运行线获批，发车时间、口岸交接点和编组要求通常受严格限制，擅自更改可能导致班列延误或产生高额罚款。

## 常见误区
- 误认为申请了运行线就等于完成了所有铁路订舱，实际上运行线获批仅代表获得了“路权”和时间窗口，仍需向车站办理具体的装车和托运手续。
- 误以为运行线可以随时修改，跨境铁路的运行线一旦确定，各段铁路局的接发车计划高度联动，微调极其困难。

> 📖 分类：**运输** / 空运单证　｜　Commodity Item Number = 商品品目编号

## 定义

Commodity Item Number（商品品目编号）是指在国际贸易与运输中，用于对特定货物进行分类和识别的标准化数字编码。它是物流单证、关务申报和运费计算的重要基础数据。

## 详细说明

- 使用场景：广泛应用于航空货运的特种货物分类、海运拼箱（LCL）货描述、铁路联运以及海关进出口申报中。
- 关键规则：该编号通常由货运代理、承运人或海关根据国际通行的商品分类标准（如 HS Code 或航空公司专有商品代码）来确定。不同的编号直接影响运价计算、监管条件及关税税率。
- 实务注意事项：在填写运单（如 AWB 或 B/L）时，必须准确提供商品品目编号。若申报错误，可能导致海关查验、运费重算、甚至因虚报品名产生罚款和清关延误。

## 常见误区

- 认为商品品目编号可以随意填写：实际上它有严格的国际标准，错误填写会导致清关受阻或运费争议。
- 将商品品目编号等同于货物的商业品名：编号是数字化的分类代码，而品名是文字描述，两者需配合使用但不可混淆。

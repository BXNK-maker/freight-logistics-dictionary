## 定义

Security Program（安保方案）是指航空货运企业、供应链经营者或港口设施等相关主体，为满足国际和国家航空与海运安全法规而制定并实施的标准化安全管理体系。该方案旨在防止非法干扰行为，保障货物在供应链各环节的安全。


## 详细说明

- 使用场景：广泛应用于航空公司、货运代理（FF）、地面代理（GHAs）以及仓储运营商申请并维持相关国际资质（如 RA3、Known Consignor 等）的全过程。
- 关键规则与标准：必须符合国际民用航空组织（ICAO）《安保手册》以及各国海关和民航局（如中国民航局、美国 TSA、欧盟相关机构）的严格合规要求。
- 实务注意事项：货代企业需根据自身业务流程动态更新安保方案，并定期对员工进行安全意识和操作培训；方案中的安保措施必须落到实处，否则面临资质暂停或巨额罚款。

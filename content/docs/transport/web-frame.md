> 📖 分类：**运输** / 船舶结构　｜　Web Frame = 强肋骨

## 定义
Web Frame（强肋骨）是指船舶内部结构中一种尺寸较大、强度更高的骨材，通常垂直安装在船体舷侧或横舱壁上。它的主要作用是增强船体局部的结构刚性，承受来自海浪、货物及外部压力的巨大负荷，确保船舶在航行和装卸作业时的结构安全。

## 详细说明
- 使用场景：广泛应用于散货船、集装箱船和油轮等各类商船的货舱及机舱内部，特别是在承受集中载荷或需要开辟大开口的区域。
- 关键规则与特点：强肋骨的间距通常是普通普通肋骨（Ordinary Frame）的整数倍（如3到5倍），其截面通常为T型或球扁钢型，设计时必须满足船级社（Classification Society）的规范要求。
- 实务注意事项：在重大件货物配载和装卸过程中，货代与操作人员需了解舱内强肋骨的位置与间距，避免货物系固点直接作用于薄弱区域，同时在进行舱内结构改装或焊接时，严禁随意切割或削弱强肋骨的连续性。

## 常见误区
- 误区一：认为强肋骨和普通肋骨的作用完全相同，只是尺寸略有差异。实际上，强肋骨是整个船体横向强力结构的核心支撑，承担着保持船体横剖面形状的关键任务。
- 误区二：在货物装载时，将强肋骨等同于普通的系固点，直接将重型机械或钢材的绑扎链挂在肋骨腹板上，这极易导致构件变形甚至破坏船体结构。

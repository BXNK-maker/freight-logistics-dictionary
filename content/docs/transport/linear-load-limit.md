> 📖 分类：**运输** / 配载平衡　｜　Linear Load Limit = 单位长度限载

## 定义
单位长度限载（Linear Load Limit，简称 LLL）是指货物在运输工具（如集装箱、拖车或飞机货舱）底部单位长度内所允许承受的最大重量。该指标通常以“千克/米（kg/m）”或“磅/英尺（lb/ft）”为单位计量。

## 详细说明
- 使用场景：主要用于评估长条形、集中载荷的重型货物（如钢管、机械设备、木材等）在运输途中的安全性，防止局部底板因压力过大而损坏。
- 关键规则：当货物的总重量在载具整体承载范围内时，如果其接触面积过小、长度较短，仍可能因为超出单位长度限载而遭到拒绝承运或被要求整改。
- 实务注意事项：在装载重型长货时，必须使用垫木（Dunnage）或底座来增加接触面积，将集中载荷分散到更长的距离上，从而确保符合载具的 Linear Load Limit 标准。

## 常见误区
- 误以为只要货物的总重量没有超过集装箱或车辆的载重上限（Payload）就绝对安全，忽略了单位长度限载导致的局部压强超标问题。
- 认为 Linear Load Limit 和 Floor Load Limit 是同一个概念，实际上前者侧重于沿长度方向的线性负荷分布，后者侧重于单位面积上的压强。

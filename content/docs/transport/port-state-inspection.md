## 定义

港口国检查（Port State Inspection，简称 PSI，常更通俗地称为 Port State Control 或 PSC）是指船舶到达外国港口时，港口国主管机关（通常是海事当局）依据国际公约对船舶的结构、设备、船员配备及生活工作条件实施的监督检查。它是国际海事安全网的最后一道防线，旨在消除不安全、不合规船舶带来的航行风险与海洋污染。

## 详细说明

- 使用场景：通常在船舶靠港装卸货物或停泊期间进行，由港口国的官方验船师（PSC官员）登轮实施突击检查。
- 关键规则与数字：依据国际海事组织（IMO）和国际劳工组织（ILO）的相关公约，如 SOLAS、MARPOL 和 MLC 2006。通常，检查率高的地区组织（如巴黎备忘录 Paris MOU、东京备忘录 Tokyo MOU）会对高风险船舶实施更频密的滞留（Detention）机制。
- 实务注意事项：若船舶在检查中被发现严重缺陷（Deficiencies），可能面临被勒令滞留港口的处罚，这将直接导致货物延误、错过船期，并产生巨额的港口滞期费和船舶运营损失。外贸与货代人员应关注承运船东的船龄及PSC检查记录。

## 常见误区

- 误区一：认为港口国检查只针对船体结构。实际上，它不仅检查硬件设备，还极其重视船员证书、实际操作能力以及船员工作生活条件（如劳工权益）。
- 误区二：认为滞留船舶的损失由货方承担。船舶因PSC检查不合格被滞留导致的船期延误，属于船东的履约责任，货主通常可依合同追究相关损失。

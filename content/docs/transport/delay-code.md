> 📖 分类：**运输** / 航班与时刻　｜　Delay Code = 延误代码

## 定义
延误代码（Delay Code）是货运物流领域中用于分类和记录货物、航班、船舶或车辆在运输过程中发生延误原因的标准字母或数字代码。通过使用这些预设的代码，承运人和物流服务商能够快速录入并追踪供应链中各个环节的异常情况，便于后续的数据统计与责任划分。

## 详细说明
- 使用场景：广泛应用于航空货运、海运集装箱运输以及快递网络中，当货物未能按原定计划（Schedules）起飞、靠泊或派送时，操作人员会在系统（如TMS或航空公司系统）中输入相应的代码。
- 关键规则或数字：国际航空运输协会（IATA）等机构制定了标准化的延误代码体系，通常由两位字符组成（如机场地面原因、天气原因、机械故障等），不同运输方式的具体代码标准可能有所差异。
- 实务注意事项：货代和外贸人员应密切关注系统中的延误代码，因为这直接关系到后续向航司或船公司索赔（Claim）、向客户解释交货期延长（Lead Time Extension）以及评估物流供应商绩效的关键证据。

## 常见误区
- 误区一：认为延误代码只是内部统计用语，与客户沟通时无关紧要。实际上，准确的延误代码是界定是否属于不可抗力（Force Majeure）及后续索赔的重要依据。
- 误区二：混淆不同运输方式的代码。航空、海运和陆运的延误代码标准并不通用，不能套用同一套系统进行查询。

> 📖 分类：**运输** / 船舶维修　｜　Class Society Recommendation = 船级社建议项

## 定义

船级社建议项（英文全称：Class Society Recommendation）是指船舶在建造或运营检验过程中，船级社（如劳氏船级社、DNV等）针对发现的非紧急性缺陷或技术改进，向船东或船厂提出的非强制性技术指导意见。虽然它不像“船级社法定要求/整改意见”（Conditions of Class / Class Notations）那样具有强制纠正性，但若长期不予处理，可能会影响船舶的适航证书和保险效力。

## 详细说明

- 使用场景：通常出现在船舶年度检验、特别检验、坞修期间，或在港口国监督（PSC）检查前进行自查时，船级社检验师针对磨损、保养或设计优化提出建议。
- 关键规则或数字：建议项通常会设定一个建议完成的时间期限或建议在下一次指定检验前落实，虽然不直接导致船舶航行证书被吊销，但船东必须向船级社反馈后续处理情况。
- 实务注意事项：在国际贸易中，租船人和货主（尤其是承运大宗散货或危险品的货主）在评估船舶适航性时，常会要求船东提供最新的船级社状态报告（Class Status Report）。如果存在大量未闭环的 Recommendation，可能会引发租船纠纷或导致货物保险人提高保费。

## 常见误区

- 误区一：认为船级社建议项和船级社整改意见（Condition of Class）性质完全相同，必须在离港前强制完成。实际上，建议项属于指导性意见，不具备即时强制性。
- 误区二：认为租船人或货主无权查阅船级社建议项。在航运实务中，干净的 Class Status（无严重滞留或未决建议项）是证明船舶适航的重要文件。

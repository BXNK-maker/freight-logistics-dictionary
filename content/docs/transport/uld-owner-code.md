> 📖 分类：**运输** / 集装器管理　｜　ULD Owner Code = 集装器属主代码

## 定义
ULD Owner Code（中文：集装器属主代码）是航空货运中用于识别航空集装器（ULD）所有权或运营人的标准化字母代码。该代码通常由3个字母组成，是喷涂或刻在ULD箱体上的唯一编号的前缀部分。

## 详细说明
- 使用场景：在航空货物运输中，货代、航空公司和地面代理需要通过ULD代码来追踪集装器的流转、交接、计费以及租借管理。
- 关键规则或数字：属主代码严格遵循国际航空运输协会（IATA）的标准进行注册与管理，通常紧随其后的是4位数字的序列号，以及末尾的1位所有权/尺寸类型字母。
- 实务注意事项：在缮制航空货运单（AWB）和ULD交接单（UCC）时，必须准确录入完整的ULD编号（含属主代码），否则会直接导致地面交接延误或产生巨额的集装器滞期费。

## 常见误区
- 误认为ULD属主代码就是航空公司代码：其实不然，除了航空公司（如CA、LH）拥有自己的ULD代码外，许多专业的集装器租赁公司也拥有独立的属主代码。
- 忽略代码的唯一性核对：在交还集装器时，若未仔细核对属主代码导致张冠李戴，原属主可能会按遗失或长期租赁向错还方追缴高额赔偿。

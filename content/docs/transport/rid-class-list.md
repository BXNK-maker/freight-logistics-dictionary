## 定义
RID Class List（铁路危险品类别清单）是指根据《国际铁路危险货物运输规则》（RID）对各类危险货物进行的分类清单。该清单明确了不同危险品的类别、性质及铁路运输的具体合规要求，是国际铁路危险品运输的核心指导文件。

## 详细说明
- 使用场景：适用于所有通过铁路方式在欧洲及相关缔约国之间运输危险货物的操作，货代和发货人在订舱、制单及贴标签时必须严格遵循。
- 关键规则或数字：RID 将危险品细分为 9 个主要类别（Class 1 至 Class 9），涵盖爆炸品、气体、易燃液体、毒性物质等。每一项危险品在清单中都对应一个 4 位数的联合国编号（UN Number），用于快速识别。
- 实务注意事项：该清单与海运的 IMDG Code 和空运的 IATA DGR 高度协调，但铁路运输有其独特的特殊限制（如隧道限制代码）。托运人必须提供准确的 RID 类别，确保危险品申报单（Dangerous Goods Declaration）信息无误，否则可能面临铁路部门的拒载或高额罚款。

## 常见误区
- 误以为 RID 的分类标准与海运（IMDG）完全一致，忽略了铁路运输在载具结构和过境国特殊规定上的差异。
- 认为只要有了品名就可以随意安排铁路危险品运输，而忽略了在 RID Class List 中查找对应的包装组（Packing Group）和特殊规定。

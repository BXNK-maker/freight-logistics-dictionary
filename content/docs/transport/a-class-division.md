## 定义

甲级分隔（英文：A Class Division）是国际航运和船舶消防安全中的一个核心概念，指由符合特定耐火和结构要求的舱壁或甲板构成的分隔结构。它主要用于防止火焰和烟气在规定时间内穿透，以保障船舶在海上航行时的消防安全与人员疏散。

## 详细说明

- 使用场景：广泛应用于各类国际航行船舶、集装箱船、油轮及客船的机舱边界、起居舱室与货舱之间的防火分隔设计。
- 关键规则或数字：根据国际海上人命安全公约（SOLAS公约）的要求，甲级分隔必须由钢材或其他同等材料制成，且结构上须能在标准耐火试验的前 60 分钟内，防止烟气和火焰通过。此外，根据温升限制的不同，还细分为 A-60、A-30、A-15 和 A-0 等级别，其中数字代表在规定时间内限制背面温升不超过 140℃ 的分钟数。
- 实务注意事项：货运代理和船舶操作人员在承运危险品或进行特种货物配载时，必须了解船舶的防火区划等级，确保货舱及周边结构的耐火性能符合 IMDG Code 等相关国际规则的要求。

## 常见误区

- 误认为甲级分隔仅指代防火涂料的厚度，实际上它对整个舱壁或甲板的材质、结构强度及整体耐火时间都有严格标准。
- 混淆 A-60 与其他级别的区别，认为数字 60 代表耐火总时间为 60 分钟，实际上它是指在标准试验下背火面温升达到限制的时间标准。

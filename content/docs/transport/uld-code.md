## 定义

ULD Code（集装器代码，全称 Unit Load Device Code）是国际航空运输协会（IATA）制定的一种标准化三位字母加数字的编码系统，用于唯一识别航空货运中使用的集装箱或集装板。通过这串代码，物流从业人员可以快速识别该集装器的类型、尺寸、底板轮廓以及所有权归属。

## 详细说明

- 使用场景：广泛应用于航空货运的舱位预定、装载规划、计费交接以及追踪查询中，是航空公司与货代之间沟通货物装载单元的标准语言。
- 关键规则或数字：代码严格由四部分组成，例如 PMC，通常结构为：首位字母表示类别（如 A 代表有底座的集装箱），第二位字母代表尺寸与底座尺寸，第三位字母表示外形轮廓和适航性；后面通常紧跟序列号和所有权代码（如 PMC12345DL）。
- 实务注意事项：在制单和交接时必须准确填写 ULD Code，代码错误会导致安检核对失败、机舱配载平衡计算错误，甚至产生严重的航空安全隐患和航空公司罚款。

## 常见误区

- 误区一：认为 ULD Code 只是随便编的内部流水号。实际上它是国际通用的标准化代码，每一位字符都有严格的行业技术含义。
- 误区二：将集装箱箱体上的序列号等同于 ULD Code。序列号仅用于区分同型号的具体单个箱子，而 ULD Code 重点在于定义其规格属性。

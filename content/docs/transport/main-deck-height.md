> 📖 分类：**运输** / 货舱设施　｜　Main Deck Height = 主货舱高度

## 定义
Main Deck Height（主货舱高度）是指全货机主甲板内部从地板到天花板的垂直净高度。它是评估飞机能否容纳超高、超大特殊货物（如大型机械设备、超高托盘等）的核心尺寸参数。

## 详细说明
- 使用场景：主要用于航空货运中的超大件货物（OOG）评估、特种包机预订以及主甲板ULD（集装箱/集装板）配载规划。
- 关键规则与数字：不同机型的Main Deck Height差异显著。例如，波音B747F的主货舱高度约为3米（约118-120英寸），而B777F和A350F等双发货机的主货舱高度通常在3米左右，但受机舱弧度影响，边缘区域的高度会呈弧形递减。
- 实务注意事项：在安排舱位时，不能仅看最大高度，必须核对货物的轮廓图（Contour），确保货物尺寸与主货舱门尺寸及舱内弧形截面完美匹配，避免因超高导致无法装载。

## 常见误区
- 误以为全货机主甲板的各个位置高度完全一致，忽略了机舱顶部弧度对货物边缘高度的限制。
- 将主货舱高度与下货舱（Lower Deck）高度混淆，下货舱通常只能容纳高度在1.6米左右的ULD。

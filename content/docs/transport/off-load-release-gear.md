## 定义

Off-load Release Gear（中文：无负荷脱钩装置）是航运与救生设备领域中的一种专用机械装置，主要用于救生艇和救助艇的快速安全释放。该装置的核心机制是确保只有当救生艇完全落水、承受的载荷被解除（即“无负荷”状态）时，才能手动或自动打开钩子完成脱钩，从而防止在悬挂状态下意外坠落。

## 详细说明

- 使用场景：主要安装在各类远洋货轮、客轮及钻井平台的重力式或自由降落式救生艇的吊艇索连接处，用于船舶应急弃船或日常演习时的收放作业。
- 关键规则或数字：根据国际海上人命安全公约（SOLAS）及国际救生设备规则（LSA Code）的要求，该装置必须配备明显的锁定指示器和防误操作保险销；现代标准通常要求其操作力符合人体工程学，确保在恶劣海况下单人也能安全操作。
- 实务注意事项：货代与船东在进行船舶物料（Ship's Stores）采购、救生设备年检或船旗国检查时，必须确保该装置符合最新IMO修正案标准，严禁使用已被淘汰的、容易带载意外脱钩的老旧型号，以防发生人员伤亡事故。

## 常见误区

- 误区一：认为无负荷脱钩装置在任何情况下都能随时拉开。实际上，如果在吊艇索仍承受船艇重力时强行操作，机械结构会自锁，无法打开，必须在水浮力支撑救生艇释放重力后方可脱钩。
- 误区二：将其与“有负荷脱钩装置（On-load Release Gear）”混淆。无负荷装置强调必须卸载后才能开舱脱钩，而有负荷装置允许在未完全落水但紧急情况下带载释放，两者的安全操作规程截然不同。

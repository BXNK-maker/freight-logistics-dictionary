> 📖 分类：**运输** / 航空安保　｜　Cargo Security Seal = 货物铅封

## 定义

货物铅封（Cargo Security Seal）是一种用于锁定集装箱箱门、卡车车厢或货舱的一次性机械锁具，旨在防止货物在运输过程中被非法开启、偷盗或篡改。每个铅封通常都印有唯一的连续编号和公司标识，是供应链安全管理的重要凭证。

## 详细说明

- 使用场景：主要用于国际海运整箱（FCL）出口、陆运集卡运输、铁路联运以及航空货运的ULD（集装箱/集拼器）物理防盗。
- 关键规则与数字：
  - 铅封必须在海关查验或发货人装箱完毕并关门后立即施加。
  - 提单（B/L）和装箱单上必须准确记录铅封号（Seal Number）。
  - 高等级的国际货物运输通常要求使用符合 ISO 17712 标准的高安全铅封（High Security Seal，通常为子弹封/Bolt Seal）。
- 实务注意事项：
  - 提货时，收货人必须核对实物铅封号与提单记录是否完全一致，若不符或铅封破损，有权拒绝提货并要求做联合验货。
  - 一旦铅封被剪断，除海关关员或授权执法人员外，任何人无权擅自更换。

## 常见误区

- 误区一：认为铅封具有极高的机械锁固功能。实际上铅封是一次性防盗和防篡改标志，其主要作用是“防君子不防小人”及提供责任追溯依据，而非防止暴力破坏。
- 误区二：铅封号码可以随意手写更改。在国际贸易中，铅封号是报关和交接的核心数据，若装船前发现铅封号错误，必须通过正规流程修改舱单信息，严禁私自替换同号铅封。

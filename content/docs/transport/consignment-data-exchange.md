> 📖 分类：**运输** / 铁路单证　｜　Consignment Data Exchange = 货运数据交换

## 定义
货运数据交换（Consignment Data Exchange，简称 CDE）是指贸易与物流供应链各方之间，通过电子化方式安全传输和共享与货物托运相关的数据和文件的技术机制。它打通了发货人、货代、承运人、海关及收货人之间的信息壁垒，实现了物流信息的实时互通。

## 详细说明
- 使用场景：广泛应用于跨境电商备货、多式联运交接、海关电子申报以及供应链上下游的可视化追踪。
- 关键规则或数字：现代 CDE 通常基于 EDI（电子数据交换）标准或 API 接口开发，要求数据传输符合 UN/EDIFACT 或 XML 等国际通用格式，确保 99% 以上的数据准确率与毫秒级响应。
- 实务注意事项：操作时必须严格遵守各国的《数据安全法》与 GDPR 等隐私条例，防止商业机密泄露；同时需注意不同系统间数据字段的映射准确性，避免因格式错位导致清关延误。

## 常见误区
- 认为 CDE 只是简单的邮件发送或文件上传：实际上它涉及结构化数据的自动解析与系统直连，远超传统人工传输范畴。
- 误以为所有平台的 CDE 标准完全一致：由于各国海关和不同承运人的系统架构存在差异，数据对接通常需要特定格式的转换与适配。

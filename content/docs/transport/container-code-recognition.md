## 定义

箱号自动识别（Container Code Recognition，简称 CCR）是一种利用光学字符识别（OCR）和人工智能技术，自动读取并识别集装箱箱体上喷印的箱号、尺寸类型代码及最大总重的技术。它广泛应用于港口、码头、堆场和海关卡口，能够大幅提升集装箱进出闸效率并减少人工错误。

## 详细说明

- 使用场景：主要应用于集装箱码头（CT）闸口、堆场龙门吊、轨道吊以及海关监管卡口，用于车辆过闸或吊装作业时对集装箱身份的秒级自动采集。
- 关键规则或数字：标准的集装箱箱号遵循 ISO 6346 标准，由 4 位字母（前三位所有者代码、第四位类别代码，通常为 U、J 或 Z）和 7 位数字（6 位序列号和 1 位校验码）组成。系统识别准确率通常需达到 98% 以上方可满足商业运营要求。
- 实务注意事项：若集装箱箱体严重锈蚀、污损、变形或喷漆剥落，可能导致识别率下降，仍需人工复核；同时，夜间或恶劣天气下的补光与摄像机角度调整对识别系统至关重要。

## 常见误区

- 认为箱号自动识别系统可以完全取代人工查验：实际上，对于破损箱、模糊箱或特殊材质箱，系统往往无法准确识别，仍需现场操作人员进行人工核对与录入。
- 混淆箱号与铅封号：CCR 技术主要针对集装箱箱体本身的 ISO 编码进行识别，通常无法直接清晰读取挂在箱门上的铅封号（Seal Number）。

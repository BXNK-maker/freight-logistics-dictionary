> 📖 分类：**运输** / 海事安全　｜　Ship Security Officer = 船舶保安员

## 定义
Ship Security Officer（简称 SSO，中文意为船舶保安员）是指由船公司委任、在船长领导下负责全船保安工作的船上高级船员。该职位是国际海事组织（IMO）《国际船舶和港口设施保安规则》（ISPS Code）规定的核心关键岗位，直接对船长负责。

## 详细说明
- 使用场景：SSO 广泛应用于所有执行 ISPS Code 的国际航行海船上。在船舶靠港、离港、航行途经高风险海域以及接收安保威胁情报时，SSO 是核心执行人。
- 关键规则或数字：根据 ISPS Code 要求，每艘船舶必须配备一名合格的 SSO，并持有海事主管机关或其授权机构签发的有效适任证书。SSO 必须定期组织船员进行保安演习（通常频次为每三个月至少一次）。
- 实务注意事项：在实际货运操作中，SSO 负责监督船舶保安计划（SSP）的落实，对登轮人员、访客及货物/行李进行身份核实和安全检查。货代和外贸人员在安排船边作业或随船验货时，必须积极配合 SSO 的安全查验与登记工作。

## 常见误区
- 误区一：认为 SSO 就是负责日常防盗和打击走私的普通船上保安。实际上，SSO 的核心职责是执行国际反恐、防范非法干扰和应对海上突发安全威胁。
- 误区二：混淆 SSO 与 CSO。SSO 常驻船上负责具体执行，而 CSO 在岸基办公，负责统筹全公司船队的保安管理并与外部港口协调。

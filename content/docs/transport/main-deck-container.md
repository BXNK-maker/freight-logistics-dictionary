> 📖 分类：**运输** / 集装器类型　｜　Main Deck Container = 主货舱集装箱

## 定义

Main Deck Container（主货舱集装箱）通常简称为 MDG 或 MDC，是指专门设计用于宽体货机或客机主甲板（Main Deck）舱内货运系统的航空集装箱。这类集装箱由于需要配合主舱的弧形舱壁和更高的载重需求，尺寸和外形通常比下货舱集装箱（Lower Deck Container）更大且更为不规则。

## 详细说明

- 使用场景：主要用于大型全货机（如 Boeing 747F、777F）或大型宽体客机（如 Airbus A350、Boeing 777）的主舱载货，适合运输超大件货物、高价值货物或大批量一般贸易货物。
- 关键规则或数字：主货舱集装箱的底部通常为标准的 125 英寸（约 317.5 厘米）或 96 英寸宽，高度可达 244 厘米至 300 厘米不等。其最大毛重（Max Gross Weight）通常在 6,800 公斤到 13,600 公斤之间，具体取决于机型舱门尺寸和锁扣系统承载力。
- 实务注意事项：由于主货舱空间有限且形状高度贴合机身弧度，装箱时必须使用符合特定 Contoured（轮廓）要求的集装箱或板（Pallet）；订舱时需严格核对货物的实际外形尺寸与机型主舱门（Main Deck Cargo Door）的净高和净宽，避免因超限无法装机。

## 常见误区

- 认为主货舱集装箱可以和下货舱集装箱通用：主货舱集装箱体积更大、底部结构和高度轮廓与下货舱完全不同，绝不能混用。
- 忽略主舱舱门尺寸限制：虽然主货舱内部空间大，但货物的进出受限于主舱侧门尺寸，常常出现“箱子放得下，舱门进不去”的情况。

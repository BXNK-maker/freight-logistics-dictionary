> 📖 分类：**运输** / 航空安保　｜　Consignment Security Declaration = 货物安全申报

## 定义

货物安全申报（英文全称：Consignment Security Declaration，简称 CSD）是一份由供应链相关方出具的官方单证，用于确认航空货运货物在运输前的安全性状态。该文件证明货物在整个保管链中已实施必要安全检查，且未受到未经授权的篡改。

## 详细说明

- 使用场景：主要用于国际航空货运出口，特别是货物从已知发货人（Known Consignor）向货代或航空公司交接时，作为证明货物符合航空安保要求的法定文件。
- 关键规则：CSD 必须包含货物的安全状态声明、安保豁免理由（如适用）、出具人身份信息及责任人的有效签名。根据国际民航组织（ICAO）及各国海关规定，未随附有效 CSD 或未通过安检的航空货物将拒绝装载。
- 实务注意事项：货代和发货人必须确保 CSD 上的信息与实际货物及主运单（AWB）保持完全一致。若在运输途中供应链安全链条断裂（如擅自拆货或中途存放于不安全场所），该 CSD 将自动失效，货物需重新接受安检。

## 常见误区

- 误认为 CSD 可以由任何普通发货人自行随意填写，实际上只有符合资质的已知发货人或受管制代理人才能出具。
- 混淆 CSD 与海关申报单，CSD 关注的是航空物理安保和反恐链条，而非关税及贸易合规申报。

## 定义

联运单一窗口数据（Single Window Intermodal Data）是指在国际货物多式联运过程中，通过单一电子平台集中采集、处理和交换海关、港口、铁路、航运及货代等多方监管与商业数据的信息化机制。该概念旨在实现“一次性提交，全网共享”，大幅提升多式联运的通关与转运效率。

## 详细说明

- 使用场景：广泛应用于海铁联运、江海联运以及跨国跨境走廊的物流节点，特别是在需要频繁转换运输方式和跨部门申报的枢纽港及内陆陆港。
- 关键规则或数字：系统通常遵循 UN/CEFACT（联合国促进贸易和电子商务中心）等国际标准进行数据建模，力求实现“单一录入”并通过 API 接口与各国海关及单一窗口（National Single Window）无缝对接。
- 实务注意事项：货代企业需确保录入的货描、重量、体积及集装箱号等基础数据在各区段零误差，否则一处报错可能导致整个联运链条的货物被统一扣留或延误。

## 常见误区

- 误区一：认为“单一窗口数据”仅适用于单一的海运或空运环节，忽略了其跨运输方式（海、陆、铁）整合的核心特征。
- 误区二：认为该数据仅由海关单方面使用，实际上它同时涵盖了商业物流节点中的港务、船公司及铁路运营方的协同需求。

> 📖 分类：**运输** / 海事安全　｜　Company Security Officer = 公司保安员

## 定义

Company Security Officer（简称 CSO，中文意为“公司保安员”或“公司保安主管”）是指由航运公司或港口设施经营人指定的、负责确保船舶保安计划或港口设施保安计划得以制定、实施和维护的高级管理人员。该职位是落实国际船舶和港口设施保安规则（ISPS Code）的核心角色之一，直接对公司最高管理层负责。

## 详细说明

- 使用场景：主要应用于国际海运、船舶管理、港口运营以及涉及海关与供应链安全的进出口物流企业中，特别是在船舶靠港申报、供应链安保审计和突发应急响应时发挥关键作用。
- 关键规则或数字：CSO 依据 IMO（国际海事组织）的 ISPS Code 设立，必须具备相应的专业资质和培训背景；其职责涵盖全公司的船舶安保，通常需与各船舶的 SSO（船舶保安员）及当地港口当局保持24小时全天候联络。
- 实务注意事项：货代与外贸从业人员在处理特种货物、危险品运输或敏感航线时，若遇到船舶安保等级提升（如保级为 Level 2 或 Level 3），往往需要直接对接 CSO 或其授权代表，以确认装卸货计划和提单安全合规。

## 常见误区

- 误区一：认为 CSO 只负责公司办公室的门禁和日常保卫。实际上，CSO 的核心职责是管理船舶和海上供应链的国际反恐与防范非法干扰，属于海运合规与风险管理范畴。
- 误区二：将 CSO 与 SSO 混为一谈。CSO 是岸基高级管理人员，负责统筹全公司多艘船舶的安保；而 SSO 是船上的具体执行人员，直接在船长领导下工作。

> 📖 分类：**运输** / 空运单证　｜　Declared Value for Carriage = 运输声明价值

## 定义

运输声明价值（Declared Value for Carriage）是指托运人向承运人特别声明的货物运输价值，通常填写在空运单（AWB）或提单（B/L）的相关栏位中。该价值主要用于突破承运人法定的标准赔偿责任限额，并以此为基础计算超额运费（Valuation Charge）。它是平衡托运人风险保障与承运人责任上限的核心商业约定。

## 详细说明

- 使用场景：主要适用于高价值货物（如精密仪器、艺术品、贵重电子产品等），当标准责任限额无法覆盖潜在损失时，托运人会主动选择声明价值。
- 关键规则或数字：国际航空货物运输中，若未另行声明，国际公约（如《蒙特利尔公约》）通常将承运人的赔偿责任限制在每公斤约 22 特别提款权（SDR）。托运人一旦声明了更高的价值，承运人通常会按超出标准限额的金额按比例收取额外的声明价值附加费。
- 实务注意事项：声明价值绝不能超过货物在目的地的实际价值，且不得超过货物的实际发票金额。同时，声明价值并不等同于购买了商业保险，它只是加重了承运人在责任期内的赔偿上限，发生货损时仍需依据实际损失和责任归属进行索赔。

## 常见误区

- 误区一：认为填写了运输声明价值就等于购买了货物保险。实际上它只是提高了承运人的赔偿上限，而非风险转移的保险合同。
- 误区二：为了理赔时多拿赔偿，故意将声明价值填得远高于货物本身的实际市场价值。这不仅无法获得超额赔偿，还可能涉嫌欺诈。

> 📖 分类：**运输** / 引航拖带　｜　Bollard Pull Test = 系柱拉力试验

## 定义
Bollard Pull Test（系柱拉力试验）是指在静态或近似静态条件下，通过专用测力计测量船舶（通常为拖轮）在最大功率输出时系缆桩所承受的最大拉力的实船测试。该测试是评估船舶动力性能、航行安全以及商业契约履约能力的核心技术手段。

## 详细说明
- 使用场景：主要用于新造拖轮交付验收、定期性能检验、船舶改装后评估，以及在承接大型海上浮吊、钻井平台拖带等特殊重吊大件项目前确认拖轮资质。
- 关键规则或数字：测试通常要求在深水、无风流干扰的标准化水域进行；测量单位通常为吨（T）或千牛（kN）；测试时主机需达到满负荷连续运转状态，并记录正车（Ahead）和倒车（Astern）的最大拉力。
- 实务注意事项：货代与项目物流经理在安排重件海运拖航时，必须查验船方的近期系柱拉力证书，确保其实际拖力与海事局或船级社审批的拖航计划相符，避免因动力不足导致海上险情。

## 常见误区
- 误区一：认为系柱拉力就是拖轮航行时的最大拖拽力。实际上，航行中的动态阻力和流速会显著降低船舶的实际有效拖力。
- 误区二：只要拖轮主机马力大，系柱拉力就一定高。螺旋桨设计、桨叶类型及船体线型等因素对最终拉力测试结果有决定性影响。

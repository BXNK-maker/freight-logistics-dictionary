> 📖 分类：**运输** / 港口服务　｜　Husbandry Agent = 船舶事务代理

## 定义

船舶事务代理（Husbandry Agent，又称船务代理）是指受船东或船舶经营人委托，在船舶停靠港口期间，专门负责处理除货物装卸和货运单证以外的船舶日常运营和后勤保障事务的代理人。他们是船舶在港期间的“大管家”，确保船员、船舶及各项补给需求得到妥善安排。

## 详细说明

- 使用场景：当船舶挂靠非母港或国外港口时，船东通常不会派驻常驻人员，而是聘请当地的 Husbandry Agent 来处理与港口当局、供应商及船员相关的各项事务。
- 关键规则与工作内容：主要职责涵盖船员换班与签证办理、安排船员就医与遣返、补充淡水、燃油及伙食补给、安排船舶日常维修保养、处理船舶垃圾排放以及协助船检等。
- 实务注意事项：在实际操作中，Husbandry Agent 需要与港口海关、边检、引航站等口岸单位密切配合；各项服务费用通常由船东预先垫付或汇款，代理需严格做好账目核对与单据留存。

## 常见误区

- 认为 Husbandry Agent 负责货物的装卸和报关：实际上，货物相关的事宜通常由承运人的装卸代理（Stevedoring Agent）或货运代理处理，Husbandry Agent 专注于船舶本身的后勤事务。
- 将 Husbandry Agent 与 Port Agent 混为一谈：Port Agent 是一个更广义的概念，包含了货运代理和船舶事务代理的所有职能，而 Husbandry Agent 往往侧重于非货物流通类的船舶日常服务。

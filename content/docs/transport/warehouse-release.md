> 📖 分类：**运输** / 提取配送　｜　Warehouse Release = 仓库放行

## 定义
Warehouse Release（仓库放行）是指货物存放于仓库（如保税仓、普通仓库或CFS拼箱仓）期间，仓库管理方在确认相关费用已清缴、海关手续已办妥及货权文件齐全后，签发给提货人或物流承运人的书面放行凭证。它是货物得物理移出仓库的关键指令。

## 详细说明
- 使用场景：主要用于进口货物提货、出口拼箱货（CFS）进仓后的装箱放行，以及保税货物的转关或内销出仓环节。
- 关键规则与要求：货主或收货人必须凭正本提单（B/L）或电放保函、海关放行信息（如进口报关单放行通知）、以及仓储费和装卸费的结清凭证，才能向仓库换取 Warehouse Release。
- 实务注意事项：仓库放行不等于海关放行，两者必须同时具备；若涉及超期仓储费（Demurrage/Storage），必须先处理好费用问题，否则仓库拒绝签发放行指令，会导致提货延误并产生额外成本。

## 常见误区
- 误区一：认为只要有海关放行条就能直接去仓库提货。实际上，必须同时取得仓库自身的 Warehouse Release，因为仓库需要核对仓储费和内部操作状态。
- 误区二：将 Warehouse Release 与 Delivery Order (D/O) 混为一谈。D/O 通常由船公司或其代理签发用于提柜或提货，而 Warehouse Release 是由具体存放货物的仓库签发的出库凭证。

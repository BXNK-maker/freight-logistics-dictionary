> 📖 分类：**运输** / 集装器管理　｜　Empty ULD Return = 空集装器返还

## 定义

Empty ULD Return（空集装器返还）是指航空货运代理人或航空公司将空运使用的集装器（Unit Load Device，简称ULD）按规定归还给航空公司或其指定集装器管理公司的操作流程。这是维持航空货运供应链周转和设备平衡的核心环节。

## 详细说明

- 使用场景：通常发生在货代完成进口货物的拆箱交付（Break-bulk）之后，或在航空公司指定的场站（Off-airport Container Depot）进行空箱交还。
- 关键规则：航空公司通常会设定严格的免费使用期限（Demurrage-free period），一般为提取货物后的3至7天不等。超时未还则会产生巨额的超期使用费（ULD Demurrage Charges）。
- 实务注意事项：返还时必须确保集装器结构完好、无严重损坏，并附带完好的底网（Nets）和绑带（Straps）。交还时需索取并妥善保存交接凭证（ULD Interchange Receipt，简称UIR），以防产生后续的责任纠纷。

## 常见误区

- 误区一：认为只要货物卸完，空集装器就可以无限期存放在仓库里。实际上，免费期过后会产生高昂的滞期费。
- 误区二：交还空集装器时不需要检查配件。如果缺少底网或门帘直接归还，货代仍需承担配件丢失的赔偿责任。

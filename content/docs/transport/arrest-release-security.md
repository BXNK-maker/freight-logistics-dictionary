> 📖 分类：**运输** / 海事法律　｜　Arrest Release Security = 扣船解除担保

## 定义
Arrest Release Security（扣船解除担保）是指船舶因海事纠纷被法院扣押后，船方或其利益相关方为使船舶恢复自由航行，向法院或扣船方提供的财务担保。该担保通常采用现金押金、银行保函（Bank Guarantee）或保赔协会（P&I Club）担保函的形式，以替代船舶本身作为索赔责任的担保物。

## 详细说明
- 使用场景：当海事索赔人（如货主、船东、港口等）因货损、运费争议或碰撞事故向法院申请扣押船舶时，船方为避免产生高昂的港口滞留费和合同违约损失，需通过提供担保来换取法院下达解扣令。
- 关键规则或数字：担保金额通常根据索赔金额、利息及诉讼费用总和来确定，一般不超过争议标的额的最高限额；担保的形式和条款必须经原告律师认可或由法院最终裁定方可生效。
- 实务注意事项：货代和外贸企业在处理此类纠纷时，必须确认保函的开立主体具有国际信誉（如一级国际银行或知名P&I协会），且管辖法院和适用法律条款要明确，否则可能面临担保无效的风险。

## 常见误区
- 误认为提供解除担保就等于承认了债务责任，实际上这仅是为了释放船舶而采取的替代性财产担保，不影响后续对案件实体责任的抗辩。
- 认为任何保险公司的保函都能被法院接受，通常只有国际认可的P&I协会担保或主流银行保函才能顺利通过法院审批。

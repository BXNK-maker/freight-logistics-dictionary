> 📖 分类：**运输** / 多式联运衔接　｜　Ramp Event = 装卸场站事件

## 定义

Ramp Event（装卸场站事件）是指在铁路货运或多式联运中，集装箱或货物在铁路场站（Ramp）进行装卸、吊装、进出闸等关键作业节点的记录。它是铁路运营商和物流服务商追踪货物运输状态、计算免费堆存期和 demurrage/detention 费用的重要时间戳。

## 详细说明

- 使用场景：主要应用于北美及欧洲等地的铁海联运（Intermodal）和铁路直达运输中，当集装箱从船舶卸下转上火车，或从公路卡车转入铁路平板车时触发。
- 关键规则或数字：Ramp Event 的记录直接决定了箱管费用的计算。通常，场站会给予收发货人一定的免费堆存期（Free Time），一般为 24 至 48 小时不等，超时则开始产生滞箱费（Storage/Demurrage）。
- 实务注意事项：货代和外贸人员必须密切关注系统中的 Ramp Event 更新（如 Ramp In / Ramp Out）。如果因为海关查验或文件缺失导致卡车无法及时提货，错过免费期，将产生高昂的场站滞留成本。

## 常见误区

- 误区一：认为 Ramp Event 只适用于航空货运的机坪操作。实际上，在物流语境下，Ramp 特指铁路装卸场站，与航空货运的 Ramp 无关。
- 误区二：混淆了 Ramp Event 与 Vessel Arrival。Ramp Event 发生时货物通常已完成海运卸船并转入内陆铁路段，属于内陆运输节点而非港口海运节点。

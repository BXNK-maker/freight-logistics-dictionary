> 📖 分类：**运输** / 救生消防　｜　On-load Release Gear = 带负荷脱钩装置

## 定义
On-load Release Gear（带负荷脱钩装置）是安装在救生艇或救助艇上的机械释放系统，允许在艇承受全部重量（即带负荷状态）的情况下安全、迅速地将艇从吊艇索上脱开。该装置对于船舶在紧急情况或恶劣海况下快速施放救生艇至关重要。

## 详细说明
- 使用场景：主要应用于远洋船舶、海上钻井平台及各类SOLAS公约适用的商船，特别是在风浪中需要紧急撤离或进行水面救助时。
- 关键规则或数字：根据国际海事组织（IMO）《国际救生设备规则》（LSA Code）的要求，该装置必须配备防误操作的安全锁止机构，且在航速高达5节的静水中也能安全释放。
- 实务注意事项：由于该装置操作不当曾引发多起严重的人员伤亡事故，国际海事组织已强制要求对传统的老旧钩子进行改造或更换为符合新标准的“纠错型”带负荷脱钩装置，船员必须定期进行专业演练和维护检查。

## 常见误区
- 认为带负荷脱钩装置可以在任何情况下随意拉开：实际上它有严格的防误操作联锁保护，只有在完全解除保险后才能触发。
- 将其与Off-load Release Gear（空载脱钩装置）混淆：空载脱钩装置只能在救生艇完全落水、吊艇索不受力时才能打开，两者适用场景完全不同。

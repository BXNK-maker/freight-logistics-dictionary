> 📖 分类：**运输** / 多式联运衔接　｜　CTU Packing Code = 货物运输组件装箱规程

## 定义

CTU Packing Code 全称为 IMO/ILO/UNECE Code of Practice for Packing of Cargo Transport Units，即《货物运输组件装箱规程》。该规程是一份由国际海事组织、国际劳工组织和联合国欧洲经济委员会联合发布的权威指南，旨在规范货物在集装箱、可移动罐柜等运输组件内的安全装载与固牢操作。

## 详细说明

- 使用场景：广泛应用于国际集装箱运输、多式联运以及港口装卸作业中，特别是涉及远洋海运和公路铁路联运的货物配载环节。
- 关键规则与要求：规程详细规定了货物的重量分布原则、衬垫与填充方法、以及使用绑扎带、木楔等加固材料的具体标准，重点强调防止货物在运输途中发生移位或坍塌。
- 实务注意事项：装箱人必须严格核实货物的物理特性与积载因数，确保危险品隔离符合规定，严禁偏载或超载，并在装箱完成后正确施封。

> 📖 分类：**运输**　｜　Ice Class = 冰级船舶

## 定义

冰级船舶（Ice Class）是指根据船级社标准专门设计和建造、能够在冰封海域安全航行的特种船舶。这类船舶通常拥有加强的船体结构、特殊的推进系统以及强大的防寒设备，以应对严苛的极地或高纬度冬季航行挑战。


## 详细说明

- 使用场景：主要用于冬季的波罗的海、加拿大东海岸、俄罗斯北极航道（NSR）以及常年冰冻的极地地区。外贸货代在承接此类航线货物时，必须核对船舶冰级是否满足当地港口或航道局的准入要求。
- 关键规则或数字：国际上主要依据波罗的海冰级规则（B/IIC规则）或各大船级社（如DNV、CCS）的标准进行分级，常见等级如1A Super、1A、1B、1C等（数字越小或后缀越高，破冰能力越强）。此外，极地水域航行还需遵守国际海事组织（IMO）的《极地规则》（Polar Code）。
- 实务注意事项：租船时若涉及冰区航行，船东和租船人需明确“冰区附加费”（Ice Surcharge）及航线安全责任。货主应提前确认船舶能否顺利靠泊冰封港口，避免因冰情导致滞期或货物延误。

## 常见误区

- 误区一：认为所有能在冬天出海的船都自带冰级。实际上，普通商船在未达标的冰区航行极易造成船体受损，必须由符合相应 Ice Class 标准的船舶执行。
- 误区二：混淆 Ice Class 与破冰船。Ice Class 指的是具备抗冰能力的普通商船或工程船，其主要功能是载货航行而非专门开辟航道。

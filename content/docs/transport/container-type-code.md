## 定义

Container Type Code（集装箱类型代码）是用于标识海运集装箱尺寸、高度及箱型特征的标准化字母数字代码。它是国际集装箱运输和单证流转中识别箱子物理属性的核心代码。

## 详细说明

- 使用场景：广泛应用于海运提单（B/L）、装货单（Shipping Order）、舱单以及堆场（CY）和码头的电子数据交换（EDI）系统中，便于各方快速识别箱型。
- 关键规则或数字：根据 ISO 6346 标准，该代码通常由 2 位字符组成。首位字母代表集装箱的尺寸长度（如 2 代表 20 英尺，4 代表 40 英尺），第二位字母或数字代表集装箱的高度及箱型特征（如 G1 代表普通干货箱，H5 代表高箱）。
- 实务注意事项：在缮制舱单和提单时，必须准确录入集装箱类型代码，否则可能导致海关查验延误、码头提箱错误或运费计算失误。

## 常见误区

- 误区一：认为集装箱类型代码就是集装箱箱号。实际上，类型代码仅代表箱子的尺寸和特征，而箱号是每只集装箱独一无二的全球唯一标识。
- 误区二：混淆箱型代码与货物性质。代码只反映箱子本身的物理结构（如普箱、冷箱），而不决定里面装载的是普货还是危险品。

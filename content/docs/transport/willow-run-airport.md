## 定义
Willow Run Airport（中文：柳径机场）是位于美国密歇根州底特律附近的一座重要货运机场，IATA代码为YIP。该机场在区域内承担着密集的航空货运和包机业务，是缓解底特律大都市区主要客运枢纽货运压力的重要补充力量。

## 详细说明
- 使用场景：主要用于全货机航班运营、包机运输以及中大型货物的集散，常用于处理汽车零部件、工业机械和电商快件。
- 关键规则或数字：机场拥有多条适合大型货机起降的跑道，24小时开放运营，能够有效避开大型客运枢纽的航班拥堵时段。
- 实务注意事项：货代在安排该机场的提货或交货时，需提前确认卡车车队的预约时间，并注意当地极端天气（如冬季暴雪）对地面运输和航班起降的影响。

> 📖 分类：**运输** / 海事安全　｜　Ship Security Plan = 船舶保安计划

## 定义

船舶保安计划（Ship Security Plan，简称 SSP）是指根据国际海事组织（IMO）《国际船舶和港口设施保安规则》（ISPS Code）的要求，为保障船舶及船上人员、货物安全而制定并经主管机关批准的综合性操作文件。该计划详细规定了针对不同保安级别的具体防范措施、应急程序以及船岸界面操作规范，是国际航行船舶不可或缺的法定保安指南。

## 详细说明

- 使用场景：适用于从事国际航行的客船和500总吨及以上的货船，在船舶靠港、航行、锚泊及进行货物装卸作业时必须严格执行。
- 关键规则或数字：根据 ISPS 规则，保安等级分为三级（一级为正常、二级为中等、三级为最高），SSP 针对每个级别规定了相应的安保响应措施；船长对执行该计划拥有最终决策权和绝对权威。
- 实务注意事项：SSP 属于高度机密的船载文件，严禁向无关人员泄密；船上必须指定一名合格的船员担任船舶保安员（SSO），负责该计划的日常落实、维护与演练，以应对海盗袭击、走私或恐怖主义威胁。

## 常见误区

- 认为 SSP 仅是一份形式化的应急预案，靠港时无需严格核查进出人员和随身行李。
- 将船舶保安计划（SSP）与船舶安全管理体系（SMS）混为一谈，忽视了保安计划专职防范非法干扰行为的特殊性。

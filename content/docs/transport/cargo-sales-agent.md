> 📖 分类：**运输** / 空运单证　｜　Cargo Sales Agent = 货运销售代理

## 定义

货运销售代理（Cargo Sales Agent）是指受承运人（如航空公司或船公司）委托，代其销售货运空间并处理相关业务的中间商。他们通常代表航空公司招揽货源、填制运单并收取运费，从中赚取佣金。

## 详细说明

- 使用场景：广泛应用于航空货运市场。中小货主和传统外贸企业通常不直接与航空公司订舱，而是通过 Cargo Sales Agent 将货物交运。
- 关键规则或数字：代理人需获得相关行业资质（如 IATA 认可资质），其核心收入来源是承运人支付的销售佣金（Commission），通常按运费的一定比例计算。
- 实务注意事项：代理人必须严格遵守航空公司的舱位预定规则和危险品运输条款。同时，代理人需承担一定的财务风险，如未能按时向航司交纳运费，可能面临信用额度被冻结或取消代理资格的风险。

## 常见误区

- 误区一：认为 Cargo Sales Agent 就是货主。实际上它是承运人的销售代理，站在航司的立场推销运力，而非直接代表买方。
- 误区二：混淆 Cargo Sales Agent 与 Freight Forwarder。前者侧重于代表航司“卖舱位”，后者侧重于代表货主“买服务并组织运输”。

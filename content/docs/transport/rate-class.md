> 📖 分类：**运输** / 空运单证　｜　Rate Class = 运价等级

## 定义
运价等级（Rate Class）是指承运人在制定运输价格时，根据货物的性质、重量、体积、运输方向或服务类型等因素，将货物划分出的不同收费档次。它是计算空运、海运或陆运运费的基础分类标准，直接决定了最终适用的费率水平。

## 详细说明
- 使用场景：广泛应用于国际航空货运（如国际航空运输协会 IATA 体系）和班轮运输中，用于区分普通货物、指定商品、特种货物及不同重量断的收费标准。
- 关键规则：在空运中常见的运价等级包括 M（起步费）、N（45公斤以下普通货物）、Q（45公斤及以上量产货物），以及特定重量断（如 +100kg, +300kg, +500kg 等），重量越大通常费率越低。
- 实务注意事项：货代在接单和制单时，必须准确识别货物的 Rate Class，因为错误的归类会导致运费试算错误，进而引发航空公司的补费通知（Debit Note）或客户投诉。

## 相关术语
- `Rate Basis（运价基准）`
- `Specific Commodity Rate（指定商品运价）`
- `General Cargo Rate（普通货物运价）`
- `Weight Break（重量分界点）`
- `Chargeable Weight（计费重量）`

## 常见误区
- 误以为 Rate Class 就是最终的运费金额，实际上它只是确定单价（费率）的分类代号，还需要乘以计费重量才能得出总运费。
- 混淆了不同运输方式的等级规则，盲目将海运的集装箱等级套用到空运的重量断等级中。

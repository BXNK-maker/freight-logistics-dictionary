> 📖 分类：**运输** / 配载平衡　｜　CG Index = 重心指数

## 定义
CG Index（Center of Gravity Index，重心指数）是衡量货物、集装箱或运输工具在装载时其重心位置偏离中心轴线程度的专业指标。它在国际货运和船舶稳性计算中起着关键作用，直接关系到运输过程中的安全性。

## 详细说明
- 使用场景：主要用于散货船配载、集装箱装箱（尤其是特种箱、超大件货物）、航空货运以及滚装船的车辆定位。
- 关键规则或数字：重心指数通常以百分比或距离偏移量（如毫米/厘米）表示。在船舶海运中，横向和纵向的 CG Index 必须控制在安全限额内，通常要求横向偏离不超过总宽度的极小百分比，以防船舶倾斜或发生货损。
- 实务注意事项：装载超重件或偏心货物时，必须在装箱单或货物交接单（D/R）中注明重心位置。若 CG Index 超标，港口码头有权拒绝吊装，或要求重新加固和调整货物位置。

## 常见误区
- 误区一：认为只要总重量不超载，货物的摆放位置就无关紧要。实际上，不合理的 CG Index 会导致严重的偏载，甚至引发翻船或坍塌事故。
- 误区二：混淆重心（CG）与浮心（CB）的概念。重心是重力的合力作用点，而 CG Index 专门用于量化装载分布的偏离程度。

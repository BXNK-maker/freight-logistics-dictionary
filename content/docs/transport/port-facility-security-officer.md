> 📖 分类：**运输** / 海事安全　｜　Port Facility Security Officer = 港口设施保安员

## 定义
港口设施保安员（Port Facility Security Officer，简称 PFSO）是指指定负责港口设施保安计划的开发、实施、修订和维护，并与船舶保安员（SSO）及公司保安员（CSO）进行协调的港口高级管理人员。该职位是根据国际海事组织（IMO）的《国际船舶和港口设施保安规则》（ISPS Code）设立的，旨在确保港口区域的人员、货运和船舶安全。

## 详细说明
- 使用场景：主要适用于国际航运码头、货运港口及相关物流枢纽的出入管理、货物装卸监控和突发应急响应。
- 关键规则或数字：根据 ISPS Code 的规定，每个港口设施都必须指定一名合格的 PFSO，并且港口必须根据安全威胁评估划分为三个保安等级（Security Level 1、2、3），PFSO 负责在不同等级下执行相应的安保措施。
- 实务注意事项：货代和外贸人员在安排危险品进出口或超大件货物进港时，常需配合 PFSO 进行安全查验、货物申报及人员进出码头作业的资质审核。

## 常见误区
- 误区一：认为 PFSO 只负责码头大门的面部识别和门卫管理。实际上，PFSO 的职责涵盖整个港口设施的风险评估、保安计划制定及与政府海事执法机构的对接。
- 误区二：将 PFSO 与普通货运代理混淆。PFSO 是港口运营方的专属安保管理岗位，而货代是代理货主办理托运和报关业务的服务商，两者分工完全不同。

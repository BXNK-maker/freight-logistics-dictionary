> 📖 分类：**组织与标准** / 公约规则　｜　ISM Code = 国际安全管理规则

## 定义
ISM Code 的英文全称为 International Safety Management Code，中文即《国际安全管理规则》。它是国际海事组织（IMO）制定的一套关于船舶安全营运和防止污染的管理标准，旨在规范船公司及船舶的安全管理体系。

## 详细说明
- 使用场景：主要适用于从事国际航行的客船、载重吨 500 总吨及以上的货船以及移动式海上钻井平台。在国际货运和船舶租赁中，船公司必须取得该证书方可合法运营。
- 关键规则与数字：该规则强制要求航运公司建立安全管理体系（SMS），并在岸基和船上指定明确的责任人。公司需获得“安全管理证书”（SMC）和“符合证明”（DOC）这两大核心合规文件。
- 实务注意事项：货代和外贸企业在选择船公司或订舱时，应关注承运船舶是否具备有效的 ISM 相关证书。如果船舶因安全管理不善被港口国监督（PSC）扣留，将直接导致货物延误。

## 常见误区
- 认为 ISM Code 仅适用于船长和船员：实际上，它不仅规范船上操作，更强调岸基管理层对船舶安全的责任和资源支持。
- 认为取得证书后便一劳永逸：该规则要求进行持续的内部审核与外部年度审核，体系文件必须根据实际运营不断更新。

## 定义

ISPS Code 是《国际船舶和港口设施保安规则》（International Ship and Port Facility Security Code）的英文简称，是国际海事组织为了应对海上恐怖主义威胁而制定的强制性保安标准。该规则旨在建立一个国际性的船舶和港口设施安全合作框架，以检测安全威胁并采取预防措施。

## 详细说明

- 使用场景：广泛应用于国际海运、船舶靠港操作以及港口区域的货物装卸与仓储环节。
- 关键规则或数字：该规则将港口设施和船舶的保安等级划分为三个级别（1级为正常状态、2级为紧张状态、3级为高度戒备状态）；同时要求船舶配备《船舶保安计划》（SSP）和《国际船舶保安证书》（ISSC）。
- 实务注意事项：货代和外贸企业在安排出货时，需留意目的港因保安等级提升（如升至2级或3级）而可能导致的高额保安附加费（ISPS费）、海关查验率上升以及船舶靠港卸货延误等风险。

## 常见误区

- 误区一：认为ISPS费是船公司随意的附加杂费。实际上，这是港口和船舶为符合国际保安标准而产生的法定安保成本，通常按每自然箱（TEU）或按票计收。
- 误区二：认为ISPS Code只对船公司有约束力。事实上，它同样对货主、拖车行、仓库等进出港口的陆路物流环节提出了严格的身份验证和货物安检要求。

> 📖 分类：**特殊货物** / 活体运输　｜　AVI Code = 活体动物运输代码

## 定义

AVI Code（全称为 Animal Transportation Code，简称活体动物运输代码）是国际航空运输协会（IATA）专门为航空货运中活体动物运输设定的三字特殊服从代码。它通常标注在航空货运单（AWB）和货标签上，用于快速识别和指示承运人及地面代理该货物包含有生命的动物。

## 详细说明

- 使用场景：广泛应用于宠物、观赏鱼、实验动物、动物园野生动物等通过航空运输的场景。
- 关键规则或数字：IATA 颁布的《Live Animals Regulations》（LAR）是全球活体动物航空运输的强制性标准。AVI 作为特殊的业务代码，必须与正确的笼具标准、喂食喂水说明以及检疫文件配套使用。
- 实务注意事项：
  - 订舱时必须提前向航司确认机型是否具备供氧和控温的载货舱（Live Animal Compartment）。
  - 必须严格核对进出口国的海关及濒危物种（CITES）证明文件，避免因证件不全导致动物滞留机场。
  - 地面操作需遵循“活体动物优先”原则，减少在停机坪的暴晒或受冻时间。

## 常见误区

- 认为 AVI Code 只适用于猫狗等常见宠物：实际上它涵盖了从蜜蜂、热带鱼到大型哺乳动物在内的所有航空运输活体生物。
- 以为有了 AVI 标签就可以随意混装：不同种类动物有严格的隔离禁忌（如捕食者与被捕食者不能同舱），绝不能盲目拼单。

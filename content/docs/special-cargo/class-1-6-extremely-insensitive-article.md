## 定义

Class 1.6 Extremely Insensitive Article（第1.6类极端不敏感物品）是危险品分类中爆炸品的最高分类，指包含极度不敏感裂变物质的物品。该类物品仅包含极其不敏感的爆轰物质，发生意外引爆或传播的概率极低。

## 详细说明

- 使用场景：主要用于军用弹药、特种爆破装置等高安全要求的危险品运输，在国际海运和空运中受到严格管制。
- 关键规则或数字：根据联合国危险品运输建议书（UN RTDG），第1.6类物品必须通过极其严苛的系列试验（如10c或10f试验），证明其即使在外壳破损的情况下，也不会产生意外引爆或从一个物品迅速传播到另一个物品的风险。
- 实务注意事项：尽管其不敏感性极高，但在操作时仍必须严格遵守 IMO 的 IMDG Code 或 ICAO 的 TI 标准。货代在订舱时必须向船公司如实申报 UN 编号（通常为 UN 0486 等），并提前准备完整的危包证和MSDS。

> 📖 分类：**特殊货物** / 危险品分类　｜　Transport Index = 运输指数

## 定义

运输指数（Transport Index，简称 TI）是一个用于危险货物（特别是放射性物质）运输的专业术语，用来标明对包装件、外包装件或集装箱规定的控制辐射水平的数字。该指数主要用于限制单一运载工具上的放射性总量，以确保运输过程中的辐射安全。

## 详细说明

- 使用场景：主要应用于空运、海运和陆运中涉及 Class 7 放射性物质（Radioactive Material）的危险品托运、舱单申报及仓库堆存管理。
- 关键规则或数字：TI 通常基于包装件表面上方 1 米处的最大辐射水平来计算。例如，若在距包装表面 1米处测得的最大辐射水平为 0.04 mSv/h，其运输指数即为 4。TI 值直接决定了货物的装载类别（如 I-白色、II-黄色、III-黄色标志）以及客机或货机的载运限制。
- 实务注意事项：货代和操作人员在审核危险品申报单（DGD）时，必须核对每个包装件上的 TI 值，并确保整票货物的总 TI 值不超过运输法规（如 IMDG Code 或 IATA DGR）规定的限额，同时满足隔离距离的要求。

## 常见误区

- 误区一：认为运输指数（TI）代表货物的重量或体积。实际上，TI 与货物的物理尺寸无关，仅与包装件外部的辐射剂量率直接相关。
- 误区二：认为所有危险品都需要计算运输指数。TI 是第 7 类放射性物质专属的控制指标，其他类别的危险品（如易燃液体、腐蚀品等）不使用此指数。

> 📖 分类：**特殊货物** / 危险品单证　｜　Third-Party Test Report = 第三方检测报告

## 定义

第三方检测报告（Third-Party Test Report）是指由独立于买卖双方、具备国家或国际认可资质的专业检测机构（如SGS、Intertek、TÜV等）出具的，对货物的物理、化学、电气性能或安全性进行测试并出具的书面证明文件。它是海关查验、目的港清关以及履行贸易合同的重要质量依据。

## 详细说明

- 使用场景：主要用于电子产品、玩具、食品接触材料、危险品、医疗器械等涉及人身安全和环保的货物，在出口报关、目的港清关或亚马逊等电商平台入仓时必须提供。
- 关键规则或数字：常见的认证标准包括RoHS、CE、FCC、REACH等。部分特殊货物（如电池产品）必须提供符合UN38.3标准的检测报告，否则航空公司或船公司会直接拒绝承运。
- 实务注意事项：货代和外贸人员需在订舱前确认报告的真实性、有效期限以及是否覆盖目标市场的法规要求，避免因报告过期或不合规导致货物被海关扣留或退运。

## 常见误区

- 认为只要有工厂自己出具的合格证就足够，忽视了海关和买家往往只认可具有CNAS或CMA资质的第三方机构报告。
- 误以为一份检测报告可以适用于所有国家和地区的清关要求，忽略了不同国家对标准和认证的差异性。

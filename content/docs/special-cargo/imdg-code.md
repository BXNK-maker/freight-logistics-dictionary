## 定义
IMDG Code 即《国际海运危险货物规则》（International Maritime Dangerous Goods Code），是由国际海事组织（IMO）制定的国际海运危险货物安全运输的强制性准则。该规则旨在规范危险货物在海洋运输中的分类、包装、标志及积载隔离，以保障船舶航行安全和船员人身健康。

## 详细说明
- 使用场景：适用于所有从事危险货物海运的国际航运、货运代理、发货人及港口作业人员，在订舱、报关、装箱及船舶配载时必须严格遵守。
- 关键规则或数字：规则按危害性质分为9大类危险品（Class 1 至 Class 9）；所有危险品均拥有一个四位数字的联合国编号（UN Number）；包装等级分为 I级（极度危险）、II级（中度危险）和 III级（轻度危险）。
- 实务注意事项：发货人必须提供准确的危包证（危险货物说明书）和MSDS（化学品安全技术说明书）；订舱时需如实向船公司申报，切勿瞒报、漏报或错报，以免引发重大海事事故并遭受严厉处罚。

## 常见误区
- 误区一：认为只要贴了危险品标签就可以直接出运。实际上，发货前必须完成准确的危险品分类、合规的危包箱（UN箱）包装以及向船公司和港口海事部门的双重申报。
- 误区二：混淆MSDS与危包证。MSDS是生产商提供的技术说明文件，不能替代海事主管机关出具的用于实际出口报关和装箱的正式危包证。

> 📖 分类：**特殊货物** / 危险品包装　｜　Radioactive Package Label = 放射性包装标签

## 定义

放射性包装标签（Radioactive Package Label）是根据国际危险品运输规则，强制贴在装有放射性物质的货包外部的专用危险品标贴。它不仅用于警示操作人员内容物具有辐射危险，还通过不同的颜色和分类标识辐射强度，是确保核材料与放射源安全运输的关键视觉凭证。

## 详细说明

- 使用场景：广泛应用于医疗同位素、工业探伤源、核燃料组件及科研样品的航空、海洋和陆路运输中，所有含放射性物质的货包在交运前必须正确粘贴。
- 关键规则或数字：标签通常分为 I-白（Category I-White）、II-黄（Category II-Yellow）和 III-黄（Category III-Yellow）三级，分类标准取决于货包表面的最大辐射水平和运输指数（Transport Index, TI）。标签上必须清晰标注联合国编号（如 UN2915）、放射性核素名称及货包活动度（贝克勒尔 Bq）。
- 实务注意事项：货代与操作人员在交接时，必须核对标签上的类别与运输指数是否与《危规》及危包证相符；标签必须粘贴在货包的相对两侧，且不能被打包带或文件袋遮挡。

## 常见误区

- 误认为所有放射性标签都长得一样：实际上标签分为白底和黄底，代表不同的辐射等级和运输指数，混淆类别会导致严重违规。
- 只要贴了标签就可以随意混装：放射性货包对隔离距离有极严格的要求，不能与普通货物或特定危险品简单堆放在一起。

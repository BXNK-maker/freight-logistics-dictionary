> 📖 分类：**特殊货物** / 危险品单证　｜　IMDG Code Declaration = 国际海运危规申报

## 定义

IMDG Code Declaration（国际海运危规申报）是指在海运危险货物装箱和出口前，托运人或其代理人向海事局及船公司正式申报货物符合国际海运危险货物规则的文件。该申报明确了危险货物的物理化学性质及应急处理措施，是保障船舶航行安全和港口作业合规的法定前置程序。

## 详细说明

- 使用场景：适用于所有通过海运进出口危险品（如化工品、锂电池、易燃液体等）的订舱与装箱环节，必须在船公司规定的截单截港时间（SI Cut-off）前完成。
- 关键规则或数字：申报时必须严格对应联合国危险货物编号（UN Number）和正确运输名称（Proper Shipping Name），并准确标注危险品类别（Class）及包装类别（Packing Group）。
- 实务注意事项：申报内容必须与实际出货的货物、危险品标签及危包证（危险货物包装使用鉴定结果单）保持完全一致，任何信息错漏都可能导致海事查验、高额罚款甚至无法开船。

## 常见误区

- 认为只要有产品MSDS（化学品安全技术说明书）就可以直接代替IMDG Code Declaration进行报关和订舱。
- 误以为危险品申报只需在开船后补办即可，忽视了必须在截单前完成海事申报的硬性规定。

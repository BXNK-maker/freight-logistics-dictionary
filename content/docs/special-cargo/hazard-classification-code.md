> 📖 分类：**特殊货物** / 危险品分类　｜　Hazard Classification Code = 危险性分类代码

## 定义

Hazard Classification Code（中文：危险性分类代码）是指在危险品物流中，用于明确标识危险货物具体危险特性的字母数字组合代码。该代码根据国际危险品运输标准对货物的物理、化学性质或毒性进行分类，是确保危险品安全运输和应急处理的核心依据。

## 详细说明

- 使用场景：广泛应用于海运、空运及陆运的危险品订舱、申报、单证制作（如危险品申报单 DGD）以及仓库存储环节。
- 关键规则或数字：根据联合国《关于危险货物运输的建议书》（TDG）及各大运输规则（如 IMDG Code、IATA DGR），危险品划分为9大类，分类代码结合了主危险类别（Class）、项别（Division，如有）以及潜正在特定情况下的兼容性代码。
- 实务注意事项：托运人必须提供准确的分类代码，错误的代码会导致海事或航空公司拒绝放行、扣货甚至产生高额罚款；部分国家对特定分类代码有更严格的本地禁运或限运要求。

- `IMDG Code（国际海运危险货物规则）`
- `IATA DGR（国际航协危险品规则）`
- `UN Number（联合国编号）`
- `Packing Group（包装类别）`
- `MSDS / SDS（化学品安全技术说明书）`

## 常见误区

- 误认为危险性分类代码就是联合国编号（UN Number），实际上分类代码反映的是危险特性，而 UN 编号是货物的具体化学品名编号。
- 忽视次要危险性（Subsidiary Risk）的代码，只申报了主危险分类代码，导致单证不符而被海关或港口当局扣留。

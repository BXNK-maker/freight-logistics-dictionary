> 📖 分类：**特殊货物** / 贵重物品　｜　Security Seal Number = 封条编号

## 定义

Security Seal Number（中文通常译为“封条编号”或“铅封号”）是指集装箱在装货完毕并加锁后，施加在箱门上的唯一性物理安全封条（Security Seal）上所标注的识别号码。它是验证货物在运输途中是否被擅自开箱或调换的关键凭证。

## 详细说明

- 使用场景：广泛应用于海运整箱（FCL）出口、拼箱（LCL）拆箱、铁路联运以及跨境公路运输中。每次加封或验封时，相关方（如发货人、场站、海关）都需要记录该编号。
- 关键规则或数字：标准的Bolt Seal（子弹封/高安全封）通常为金属材质，其编号必须同时体现在海运提单（Bill of Lading）、装箱单（Packing List）以及进出港交接单（Interchange Receipt）上。
- 实务注意事项：装箱后必须核对封条号与单证是否完全一致（包括字母和数字）。若封条损坏、遗失或号码不符，收货人有权拒绝提货，港口海关也可能拒绝放行并要求查验。

## 常见误区

- 误区一：认为封条编号只是一个普通的流水号，输错一两位数字无关紧要。实际上，单证与实物封条号不符会导致目的港清关延误甚至产生高额罚款。
- 误区二：只要集装箱锁上了就行，不需要记录封条号。如果没有在提单和交接单上准确记录该编号，一旦发生货损货盗将难以厘清责任。

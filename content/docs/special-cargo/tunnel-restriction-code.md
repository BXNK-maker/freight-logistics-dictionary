> 📖 分类：**特殊货物** / 危险品分类　｜　Tunnel Restriction Code = 隧道限制代码

## 定义

隧道限制代码（Tunnel Restriction Code）是欧洲危险货物道路运输协定（ADR）中的一项重要分类代码，用于标明危险货物在公路隧道中通行时的受限等级。它由大写英文字母表示，决定了特定危险品是否被允许通过某类欧洲公路隧道。


## 详细说明

- 使用场景：广泛应用于涉及欧洲公路运输的危险品货运中，特别是当货车需要穿越阿尔卑斯山等地的长距离公路隧道时。
- 关键规则或数字：ADR将公路隧道划分为A至E共5个类别（A类最宽松，E类最严格）。隧道限制代码共分为两组（无分类和配有特定字母如B、C、D、E及其组合），若货物的代码比隧道的限制类别更严，则严禁通行。例如，代码为D的货物禁止通过D类和E类隧道。
- 实务注意事项：货代和发货人在制作危申报文件时，必须核对MSDS（化学品安全技术说明书）中的隧道限制代码，并提前规划好绕行路线，避免因路线违法通行而面临巨额罚款或扣车风险。

## 常见误区

- 误区一：认为只要危险品能装船或装飞机，就能随意走陆路隧道。实际上，公路隧道的防火和通风标准各异，对危险品的限制比海运和空运更加细化。
- 误区二：认为所有危险品都需要查询隧道限制代码。实际上，部分低风险危险品在ADR规定中不受隧道限制，代码通常标注为（-）。

> 📖 分类：**特种货运**　｜　Class 2 Gases = 第2类气体

## 定义

Class 2 Gases（第2类气体）是联合国危险品运输分类（TDG）中的核心类别，涵盖在常温常压下呈气态或在特定温度下液化、加压溶解的气体。该类别不仅包括纯净气体，还包括气态货物的混合物以及含有一种或多种其他类别危险品的气体。


## 详细说明

- 使用场景：广泛应用于工业制造、医疗急救、冷链运输、实验室科研及民用生活等领域，常见如氧气、氮气、液化石油气（LPG）及各类气雾剂。
- 关键规则或数字：根据物理状态和化学性质，该类别细分为三个子项：第2.1项易燃气体（如甲烷）、第2.2项非易燃无毒气体（如氮气、二氧化碳）以及第2.3项有毒气体（如氯气）。运输时必须严格按照 IMDG Code 或 ICAO TI 标准张贴菱形危险品标签。
- 实务注意事项：在国际货运中，托运人必须提供正确的危包标示，确保钢瓶或气罐经过压力检测且阀门密封完好。集装箱或车辆运输此类货物时，必须保持良好的通风条件，严格禁止暴晒与碰撞。

## 常见误区

- 认为所有钢瓶只要没有液体流出就是安全的，忽视了高压气体在受热或跌落时极易发生物理爆炸的风险。
- 混淆非易燃气体（Division 2.2）与普通普货，误以为不燃或无毒就可以不按危险品流程进行订舱和申报。
- 忽略气雾剂（Aerosols）也属于第2类气体的范畴，在拼箱（LCL）操作时未将其按危险品规范管理。

> 📖 分类：**特殊货物** / 危险品单证　｜　Segregation Plan = 隔离配载计划

## 定义

隔离配载计划（Segregation Plan）是指在国际货物运输中，特别是危险品运输时，为了防止性质相抵触的货物在舱内或集装箱内发生相互反应而制定的具体货物摆放与隔离方案。该计划依据国际海运危险货物规则等标准编制，是保障船舶与货运安全的关键技术文件。

## 详细说明

- 使用场景：主要用于危险品（Dangerous Goods）拼箱、散货船舱配载以及大型集装箱船舶的危险品配载审核阶段。
- 关键规则或数字：必须严格遵守 IMDG Code 中的隔离等级要求，常见隔离级别包括“远离”（Away from）、“隔开”（Separated from）、“在全隔舱或舱面隔开”（Separated by a complete compartment or hold as transversely）以及“在纵向中隔舱或舱面隔离”（Separated longitudinally by an intervening complete compartment or hold）。
- 实务注意事项：订舱时必须提供准确的 UN Number 和 Class；配载图需经船长或专业危险品申报员确认方可装船；严禁将酸性物质与碱性物质等禁忌货物混装。

## 常见误区

- 认为只要贴了危险品标签就可以装在同一个集装箱里，忽视了不同类危险品之间的化学反应风险。
- 仅凭经验肉眼判断货物是否可以混装，而不去核对 IMDG Code 的配载隔离表。

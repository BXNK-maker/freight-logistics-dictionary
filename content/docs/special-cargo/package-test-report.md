> 📖 分类：**特殊货物** / 危险品包装　｜　Package Test Report = 包装试验报告

## 定义
包装试验报告（Package Test Report）是指由独立检测机构依据国际或国家标准，对货物运输包装进行跌落、振动、压载等物理与环境模拟测试后出具的正式评估文件。该报告用以证明包装具备承受供应链各环节风险、保护内装物安全的能力，是评估运输损耗责任与合规通关的重要凭证。

## 详细说明
- 使用场景：广泛应用于电子产品、精密仪器、危险品、医疗器械及高货值商品的出口海运与空运中，尤其常见于出口美国、欧盟等对环保与安全包装有强制要求的市场。
- 关键规则或数字：常见的测试标准包括 ISTA（国际安全运输协会）系列标准（如 ISTA 3A、ISTA 7D）以及 ASTM D4169 等。测试项目通常涵盖温湿度预处理、定频或随机振动测试、低气压（航空运输模拟）以及不同高度的跌落测试。
- 实务注意事项：货代与外贸人员应在订舱和交货前确认进口国海关或买家是否强制要求提供特定标准的 Package Test Report。若涉及危险品运输，包装测试报告必须与危包证（危险货物运输包装使用鉴定结果单）的申请严格对应，否则将面临无法出运或海关扣货的风险。

## 常见误区
- 认为只要产品质量合格就不需要做包装测试：实际上，许多产品本身无损，但因包装设计无法承受长途海运的温湿度变化和堆码压力而导致破损，责任仍在于包装。
- 将工厂内部的简易跌落测试等同于官方试验报告：只有具备资质的第三方实验室出具的 Package Test Report 才能被海关、保险公司及海外买家广泛认可。

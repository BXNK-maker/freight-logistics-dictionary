> 📖 分类：**特殊货物** / 冷链设备　｜　Set Point Temperature = 设定温度

## 定义

设定温度（Set Point Temperature）是指冷藏集装箱、冷藏车或冷库等温控运输设备内部，为妥善保存特定货物而设定的目标运行温度。它是冷链物流中控制货物环境温度的核心参数，直接决定了温控设备制冷或制热的运行标准。


## 详细说明

- 使用场景：广泛应用于鲜活农产品、冷冻肉类、乳制品、化工危险品以及医药疫苗等对温度敏感的货物运输全过程。
- 关键规则：设定温度必须根据货主要求和货物特性（如水果的呼吸热、药品的储存规范）精确设定；在航运实务中，拼箱或整箱冷藏货（Reefer Cargo）的设定温度必须准确无误地录入订舱单（Booking）和提单（B/L）。
- 实务注意事项：装箱前必须预冷货物至设定温度；装箱时货物堆码不得超过冷箱内壁的红线标志（Red Line），以免阻碍冷风循环，导致箱内温差过大。

## 常见误区

- 误以为设定温度就是货物的当前实际温度，忽略了货物自身呼吸热或外界环境对箱温的影响。
- 认为只要设定了温度，冷箱就能把高温货物快速冷却下来，而不知冷箱的主要功能是“维持温度”而非“冷却货物”。

> 📖 分类：**特殊货物** / 危险品包装　｜　Package Reference Number = 包装件参考编号

## 定义
包装件参考编号（英文全称：Package Reference Number）是发货人或物流服务商为特定货件中的某一个独立包装件分配的内部识别代码。它通常由数字、字母或条形码组成，用于在复杂的运输过程中追踪和管理单个包装。

## 详细说明
- 使用场景：主要应用于多件货（Multi-piece shipment）的国际快递、B2C跨境电商小包以及分拣要求严格的仓储物流中，方便精确锁定具体某箱货物。
- 关键规则或数字：该编号通常由发货人自定义，长度一般在 5 到 30 位字符之间；在同一票货中，每个包装件的参考编号必须具有唯一性，不能重复。
- 实务注意事项：发货人在打印运单或标签时，务必确保包装件参考编号与商业发票及装箱单上的箱号数据一一对应，否则在海关查验或目的港分拣时极易引发错乱。

## 常见误区
- 误区一：认为包装件参考编号就是国际快递的主运单号。实际上主运单号针对整票货，而参考编号针对单件货。
- 误区二：认为所有承运商都会强制要求填写包装件参考编号。部分承运商将其视为可选字段，但填写有助于提升异常件的查询效率。

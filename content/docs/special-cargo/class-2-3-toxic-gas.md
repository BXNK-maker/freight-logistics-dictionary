> 📖 分类：**特殊货物** / 危险品　｜　Class 2.3 Toxic Gas = 第2.3类毒性气体

## 定义
Class 2.3 Toxic Gas（第2.3类毒性气体）是危险品运输分类中的一个重要类别，指在海运、空运及陆运中被证明对人类健康有强烈毒害或腐蚀性的气体。这类气体吸入或经皮肤接触后极易导致死亡或严重健康损伤，国际海运危险货物规则（IMDG Code）对其包装和运输有着极为严格的限制。

## 详细说明
- 使用场景：常见于化工原料、农药制造、半导体行业及特殊工业气体的国际贸易运输中，如氯气、硫化氢、氰化氢等。
- 关键规则或数字：根据联合国危险货物运输建议书，该类气体通常具有极低的半数致死浓度（LC50值，一般小于或等于5000 mL/m³）。在运输时必须张贴带有骷髅头标志的菱形白色2.3类危险品标签。
- 实务注意事项：订舱时必须向船公司或航空公司如实申报，并提前提供危包证（危险货物包装证书）或相关官方批文。多数港口对该类货物实行严格的危化品直装直取或限制堆存时间，严禁与食品、强酸等禁忌货物混装。

## 常见误区
- 认为只要气体没有气味或颜色就不是毒性气体，忽视了诸如一氧化碳等无色无味但属于Class 2.3的高危气体。
- 混淆了第2.2类气体和第2.3类气体，误将带有毒性的压缩气体当作普通压缩气体进行普货或简易危险品报关。

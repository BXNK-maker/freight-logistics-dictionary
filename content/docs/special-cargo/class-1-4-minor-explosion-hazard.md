> 📖 分类：**特殊货物** / 危险品分类　｜　Class 1.4 Minor Explosion Hazard = 第1.4类 轻微爆炸危险

## 定义

Class 1.4（第1.4类）是指在运输过程中呈现轻微爆炸危险的危险品类别，英文全称为 Minor Explosion Hazard。该类物品如果被点燃或引爆，其危险效应主要限制在包装件内部，通常不会射出任何碎片，且外部的火 M. 也不至于引发包装内几乎所有内容物的瞬间爆炸。

## 详细说明

- 使用场景：常见于各类烟花爆竹零售品、汽车安全气囊模块、救生设备中的小型引信以及部分军用弹药民用化产品的国际运输。
- 关键规则或数字：根据国际海运危险货物规则（IMDG Code）和国际航空运输协会危险货物规则（IATA DGR），Class 1.4 通常细分为 1.4S、1.4G 等兼容性组别。其中 1.4S 最为常见，指其危险效应仅限于包装件内部，即使在外包装着火时也不会妨碍灭火或其他应急响应。
- 实务注意事项：尽管危险程度较轻，但仍属于第1类爆炸品，订舱时必须向船公司或航空公司如实申报联合国编号（如 UN0337、UN0012 等），并提供危包证。舱位通常有限制，且需要远离热源存放。

## 常见误区

- 认为 Class 1.4 属于普通货物：由于名称包含“轻微”，部分货主误以为其可以按普货瞒报或夹带，这是严重的违规行为，一经查处将面临巨额罚款。
- 忽视兼容性组别的差异：虽然同属 1.4 类，但 S 组与其他字母组（如 G 组）在混装和隔离要求上有很大不同，不能盲目混淆堆存。

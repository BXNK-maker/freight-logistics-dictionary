> 📖 分类：**特种货运**　｜　Class 3 Flammable Liquids = 第3类易燃液体

## 定义
Class 3 Flammable Liquids（第3类易燃液体）是联合国危险货物运输（TDG）分类中的一个核心类别，指闭杯闪点不超过60℃的液体，或在液态时加热至闪点及以上温度的液体，以及闪点高于60℃但以高温状态运输的液体。这类货物在常温下极易挥发并形成爆炸性混合气体，具有高度的火灾与爆炸危险性。

## 详细说明
- 使用场景：广泛应用于化工、医药、新能源、涂料及日化行业，常见货物包括油漆、稀释剂、汽油、酒精、香水、乙醇以及各类有机溶剂。
- 关键规则或数字：国际海运（IMDG Code）和空运（IATA DGR）对其包装根据危险程度划分为三个等级（PG I 极度危险、PG II 中度危险、PG III 轻度危险）；闪点（Flash Point）和沸点是判定具体包装等级的核心指标。
- 实务注意事项：订舱时必须准确提供MSDS（化学品安全技术说明书）和UN编号；运输和装卸过程中必须严格执行防火、防爆、防静电措施，通常需要加贴红色的第3类危险品标志，并妥善安排隔离与通风。

## 常见误区
- 只要是液体且易燃，就一定属于第3类：误区。部分液体的闭杯闪点虽然高于60℃，但在特定高温工艺下运输仍需按危险品管控，而有些固体或膏状物因含有溶剂也可能需按第3类申报。
- 闪点越高的液体越危险：误区。恰恰相反，闪点越低说明该液体在常温下越容易挥发并被点燃，其危险程度（Packing Group）通常越高。
- 只要外包装贴了危险品标签，拼箱（LCL）时就可以随意与其他货物混装：误区。第3类易燃液体必须严格遵守IMDG Code的隔离表要求，绝不能与氧化剂、爆炸品等禁忌货物混装在同一集装箱内。

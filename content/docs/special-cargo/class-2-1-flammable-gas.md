> 📖 分类：**特殊货物** / 危险品　｜　Class 2.1 Flammable Gas = 第2.1类易燃气体

## 定义

Class 2.1 Flammable Gas（第2.1类易燃气体）是联合国危险货物运输建议书（UN Model Regulations）中对危险品的分类之一，指在20°C和101.3 kPa标准压力下，与空气的混合物达到13%及以下时可燃，或者爆炸下限小于12%的气体。这类气体极易燃烧，遇明火、高热或静电极易发生爆炸，在国际货运中属于严密监控的危险品类别。

## 详细说明

- 使用场景：常见于液化石油气（LPG）、天然气（LNG）、打火机气体、乙炔、气雾剂（如喷雾发胶、杀虫剂）等化工品和日常消费品的国际运输。
- 关键规则或数字：在国际海运（IMDG Code）和空运（IATA DGR）中，该类别必须张贴底色为红色的菱形危险品标签，中央印有火焰图案和数字“2”。运输时必须严格核对 UN 编号（如丙烷的 UN1978，打火机的 UN1050 等）。
- 实务注意事项：订舱时必须如实申报，提供危包证（危险货物包装证书）或符合要求的压力容器证明。船公司和航空公司对这类货物有严格的积载要求，通常需远离热源，且往往被限制在特定的甲板或货舱区域。

## 常见误区

- 认为普通压力罐装喷雾（如发胶）不是危险品：含有易燃气体的气雾剂即使体积较小，也同样属于 Class 2.1，不能按照普通货物瞒报或夹带出口。
- 只要是气体就能走空运：部分高压或极易燃的 Class 2.1 气体属于客机禁运物品（Forbidden on passenger aircraft），仅限货机运输（Cargo Aircraft Only），甚至完全禁止航空运输。

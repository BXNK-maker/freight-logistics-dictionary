> 📖 分类：**特殊货物** / 危险品包装　｜　Packaging Specification Code = 包装规格代码

## 定义

包装规格代码（Packaging Specification Code）是国际货物运输中用于标准化识别和描述货物包装类型、材质及尺寸的代码系统。它通过简短的字母数字组合，向承运人和海关准确传达货物的具体外包装特征。

## 详细说明

- 使用场景：广泛应用于海运拼箱、空运货物申报、危险品运输及跨境电商仓储管理中，是EDI（电子数据交换）和舱单传输的标准数据项。
- 关键规则或数字：该代码通常依据联合国危险货物运输专家委员会制定的标准（如 UN Packaging Code）或各国际物流企业的内部编码规则编排，常见结构包含材质代号（如 4G 表示纸箱）和类别代号。
- 实务注意事项：报关与订舱时必须确保填写的包装代码与实际货物物理包装完全一致，代码错误可能导致海关查验、安检退单或运费重算。

## 常见误区

- 误认为包装规格代码仅适用于危险品运输，实际上普通普货在现代智能物流和报关中也广泛使用该代码来提升自动化处理效率。
- 将包装代码与毛重、体积等物理数据混淆，忽略了代码本质上是对“容器类型与结构”的描述。

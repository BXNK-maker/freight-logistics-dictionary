## 定义

EMS Guide（船载危险品应急措施表）是国际海事组织（IMO）为应对载运危险货物船舶上发生火灾或溢漏事故而制定的官方指导手册。它是《国际海运危险货物规则》（IMDG Code）的重要补充文件，旨在为船员提供标准化、快速且安全的应急处置程序。

## 详细说明

- 使用场景：当船舶在海上运输过程中发生危险品泄漏、包装破损、化学反应起火或爆炸等紧急情况时，船长和大副必须立即查阅本指南以采取正确的应对措施。
- 关键规则或数字：EMS 指南主要分为两大应急表格部分：第一部分是“F”表（Fire，针对各类火灾事故的灭火原则）；第二部分是“S”表（Spill，针对各类物质溢漏事故的清理与防护）。每一种危险品在 IMDG Code 的危险品一览表中都会明确标注对应的 EmS 编号（例如 F-A, S-S）。
- 实务注意事项：货代和发货人在制作危申报及装箱单时，必须准确提供危险品的联合国编号（UN No.）和正确运输名称（Proper Shipping Name），以便船方核对并匹配正确的 EMS 指南；船方也必须在开航前确保船员熟悉该指南的操作规程。

## 常见误区

- 误区一：认为 EMS Guide 只适用于航空运输或陆运。实际上，它专门针对海上船舶运输环境，重点考虑了船舶封闭空间、海上救援延迟等特殊因素。
- 误区二：将 EmS 编号与危险品的类别（Class）混淆。EmS 编号是根据物质的具体化学性质和危险特性单独划分的，同类别的不同危险品可能对应完全不同的消防或溢漏处理程序。

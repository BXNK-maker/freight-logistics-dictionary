> 📖 分类：**保险理赔** / 投保实务　｜　Insured Cargo Description = 承保货物明细

## 定义
Insured Cargo Description（承保货物明细）是指在货运保险单中对被保险货物的品名、材质、包装、数量及标记等特征进行具体列明的文字说明。它是保险人评估风险、确定费率以及理赔时核对货物身份的核心依据。

## 详细说明
- 使用场景：在向保险公司或货运代理投保时使用，通常填写在货运险保单或投保单（Marine Cargo Insurance Proposal）的指定栏目中。
- 关键规则与要求：货物描述必须与实际发运的货物、商业发票及提单上的品名保持高度一致。若运输敏感货物或二手设备，需提供更详细的规格型号。
- 实务注意事项：避免使用过于笼统的词汇（如“General Cargo”或“Accessories”），否则在发生货损时，保险公司可能以“品名不符”或“未真实披露风险”为由拒赔。

> 📖 分类：**物流金融** / 出口信保　｜　Protracted Default = 长期拖欠风险

## 定义

Protracted Default（长期拖欠风险）是指买方在货物交付或账单到期后，超过约定时间（通常为 60 天至 90 天以上）仍未能支付货款的信用风险。它是国际贸易和货运物流中信用保险承保的核心风险之一，直接威胁企业的现金流。

## 详细说明

- 使用场景：主要应用于出口信用保险、物流供应链金融以及国际贸易中的赊销（O/A）结算方式。当海外买家因资金链断裂或恶意拖延迟迟不付款时触发。
- 关键规则或数字：在国际贸易信用保险中，Protracted Default 通常有明确的等待期（Waiting Period），常见规定为账单到期后满 90 天买方仍未付款，即可向保险公司正式提出理赔申请。
- 实务注意事项：外贸企业和货代在操作赊销业务时，必须密切监控买家的付款周期。一旦临近账期应及早催收，并注意保留完整的运输单据（如 B/L、POD）和商业发票，以便在触发长期拖欠时作为索赔凭证。

## 常见误区

- 误区一：认为只要买家迟付几天就属于长期拖欠。实际上，合同约定的账期内或未达到保险条款规定的等待期（如 90 天）前，不能定性为 Protracted Default。
- 误区二：认为 Protracted Default 等同于买方彻底破产。拖欠只是买方暂时或长期未能付款，买方可能仍具存续资格，但拒绝或无力履行支付义务。

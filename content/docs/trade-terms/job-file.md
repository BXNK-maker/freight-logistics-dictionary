> 📖 分类：**贸易术语** / 货代实务　｜　Job File = 业务档案夹

## 定义

Job File（业务档案夹，通常也简称 Job）是指货运代理企业在处理具体一票进出口货物运输时，将所有相关文件、单证和财务记录汇集并归档的业务卷宗。它是整个运输流程中信息流转、操作跟进和成本核算的核心载体。

## 详细说明

- 使用场景：广泛应用于海运、空运及陆运代理的日常操作中，从客户询价、接受委托、订舱、报关、提货直到货物签收和财务结算的全生命周期管理。
- 关键规则：每一票独立的业务都必须建立唯一的 Job File（通常系统会自动生成唯一的 Job No. 或 Reference No.），所有后续的提单、发票、费用明细均需关联此编号，确保业务的可追溯性。
- 实务注意事项：随着行业数字化发展，Job File 绝大多数已转化为电子档案（TMS系统中的电子卷宗）。操作人员必须保证单据上传的及时性与准确性，避免因文件缺失导致放货延误或财务审计风险。

## 常见误区

- 误区一：认为 Job File 仅仅是纸质文件的物理归档。实际上，它涵盖了从业务发生到结束的所有电子数据、邮件往来和系统记录。
- 误区二：将 Job File 与客户档案（Client Profile）混淆。Job File 针对的是“单票业务”，而客户档案针对的是“商业伙伴”。

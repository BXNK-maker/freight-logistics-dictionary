> 📖 分类：**贸易术语** / 外贸制度　｜　Import Agent Scheme = 进口代理制

## 定义
进口代理制（Import Agent Scheme）是指国内买方由于没有进出口经营权或相关专业资质，委托有资质的专业外贸代理公司或货运代理企业以代理人名义为其办理进口通关、商务洽谈及物流配送等全套服务的贸易与物流运作模式。该机制有效解决了中小企业及非专业买方在国际采购中的资质壁垒与合规难题。

## 详细说明
- 使用场景：主要适用于无进出口权的中小企业、个人买方，或不熟悉特定品类商品复杂监管条件（如需特殊许可证、机电产品自动进口许可）的采购商。
- 关键规则与流程：代理企业接受委托签署进口代理协议，以自身名义对外签订商务合同并行使报关、报检权，但货物的所有权和最终商务风险仍归属于实际买方（委托人），代理方通常收取一定比例的代理费或赚取服务差价。
- 实务注意事项：在操作中需厘清法律责任，明确外汇收支必须遵循“谁进口谁付汇、谁出口谁收汇”的合规原则，同时注意防范海关对申报价格审价及商品归类错误的连带风险。

## 常见误区
- 误认为进口代理公司承担货物的最终质量与商业风险：实际上代理方仅提供代办服务，货物质量瑕疵和商业纠纷仍需由实际买方承担。
- 混淆收货人与代理人身份：在海关申报和提单（B/L）显示上，代理人虽作为名义收货人，但实际物权和最终税务责任通常属于委托人。

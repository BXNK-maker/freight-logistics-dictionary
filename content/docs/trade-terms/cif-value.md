> 📖 分类：**贸易术语** / 价格条款　｜　CIF Value = 到岸价值

## 定义

CIF 是 Cost, Insurance and Freight（成本、保险费加运费）的缩写，指卖方在装运港将货物装上船或交付给承运人，并支付将货物运至目的港所需的运费和最低险别的保险费。CIF Value（到岸价值）即在此贸易术语下计算出的货物总价值，常用于海关申报、关税计算及贸易统计。

## 详细说明

- 使用场景：主要适用于水上运输方式（海运和内河航运），在国际大宗商品交易和传统外贸中极为常见。
- 关键规则或数字：根据国际商会（ICC）《INCOTERMS》规定，风险在货物于装运港越过船舷时由卖方转移给买方，但费用由卖方承担至目的港。按惯例，保险金额通常按 CIF 货价加成 10%（即 CIF × 110%）投保。
- 实务注意事项：CIF Value 虽然包含了运费和保险费，但买方需要注意，卖方购买的通常只是“最低责任险”，若买方需要更全面的保障，应与卖方协商增加保险费或自行投保。此外，目的港的码头操作费（THC）等卸货费用是否包含在内，需根据具体的租船合同条款（如 LINER TERMS）明确约定。

## 常见误区

- 认为 CIF 是“货到目的港后才交货”：很多新手误以为 CIF 类似快递的送货上门，事实上，风险在装运港就已经转移给买方，货物在海上的损耗风险由买方承担。
- 混淆海关申报的 CIF Value 与合同成交价：在进口报关时，若贸易术语为 FOB，海关审价时会自动将运费和保险费计入，折算为 CIF Value 作为征收关税的完税价格基础。

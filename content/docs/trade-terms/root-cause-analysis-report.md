> 📖 分类：**贸易术语** / 质量检验　｜　Root Cause Analysis Report = 根本原因分析报告

## 定义

Root Cause Analysis Report（根本原因分析报告，简称 RCA 报告）是一份用于深入追查物流事故、货物受损、严重延误等异常事件根源的专业文件。它通过系统性排查，找出导致问题发生的根本原因，并提出针对性的纠正和预防措施（CAPA），以防类似问题再次发生。

## 详细说明

- 使用场景：通常在发生重大货损货差、海关查验扣货导致交货严重延误、危险品瞒报事故或客户发起严重客诉时，由货代或物流服务商向客户或保险公司出具。
- 关键规则或数字：一份合格的 RCA 报告通常遵循“5Why（五个为什么）”分析法，至少进行 3 到 5 个层级的追问以触及核心本质；同时，针对查出的问题需在 24 到 48 小时内给出初步响应，并在 5 到 7 个工作日内提交完整报告。
- 实务注意事项：撰写时应避免流于形式或寻找借口（如归咎于“不可抗力”），而应侧重于可落地的流程优化，例如修改SOP（标准作业程序）、加强仓库装箱复核机制或重新评估供应商资质。

## 常见误区

- 误区一：将“根本原因”等同于“直接原因”。例如，将货物受损的根本原因归结为“暴雨导致海水倒灌”，而忽视了仓库选址不当或未提前做好防汛演练的深层管理疏漏。
- 误区二：RCA 报告等同于推卸责任的公文。部分从业人员将其视作应对客户质问的敷衍手段，只做表面文字游戏，没有真正落地整改动作，导致同类问题反复出现。

> 📖 分类：**贸易术语** / 价格条款　｜　FOB Value = 离岸价值

## 定义

FOB Value 的英文全称为 Free on Board Value，中文通常译为“离岸价值”或“FOB货值”。它是指货物在装运港越过船舷（或货交承运人）之前的货物本身价值，通常包含货物的出厂价、包装费、内陆运输费及出口报关杂费，但不包含海运费和保险费。

## 详细说明

- 使用场景：主要用于国际贸易合同中的价格条款确定、海关进出口统计申报、外汇核销、国际收支平衡表编制，以及投保货物运输险时计算保费的基数。
- 关键规则或数字：根据国际商会（ICC）的 Incoterms 规则，在 FOB 术语下，风险与费用以“装运港船舷/船上”为界。FOB Value 仅体现货物装上船前的累计成本，买方需承担后续的 Main Carriage（主运费）和 Marine Insurance（海运保险费）。
- 实务注意事项：在向海关申报时，必须准确区分 FOB Value 与 CIF Value，切勿将国际运保费计入 FOB Value 中，否则会导致完税价格和统计数据失真。如果采用其他贸易术语（如 CIF 或 CFR），核算 FOB Value 时需要从总货值中扣除运费和保险费。

## 常见误区

- 认为 FOB Value 等同于工厂交货价（EXW Value）：实际上，FOB 货值不仅包含产品本身成本，还涵盖了国内工厂到装运港的内陆运费、出口报关费等装船前产生的所有费用。
- 混淆了 FOB 贸易术语下的“风险划分点”与“所有权转移点”：FOB Value 仅代表价格构成和费用分摊节点，并不直接等同于货物所有权的法律转移时刻。

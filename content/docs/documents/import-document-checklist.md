> 📖 分类：**单证** / 贸易单证　｜　Import Document Checklist = 进口单证清单

## 定义

Import Document Checklist（进口单证清单）是指在货物进口清关和提货前，由货运代理、报关行或收货人整理的一份核对清单。它用于系统性地检查各项进口单证是否齐全、准确、合规，是确保货物顺利通过海关查验和物流放行的关键前置工具。

## 详细说明

- 使用场景：通常在货物运抵目的港前或抵达后发放给收货人，用于收集并核对发票、箱单、提单及各类特许审批文件。
- 关键规则或数字：一般要求在船到港前 2-3 个工作日完成核对，以避免因单证不符产生滞箱费、滞港费或海关罚款。
- 实务注意事项：重点核对商业发票上的总金额、币别与合同是否一致；提单（B/L）上的唛头、件数、重量必须与舱单数据完全吻合；对于食品、医疗器械等特殊商品，清单必须包含对应的监管证件。

## 常见误区

- 误区一：认为进口单证清单就是报关单。实际上，清单只是内部核对的工具，而报关单是向海关正式申报的法律文书。
- 误区二：只要有单证就行，不需要提前核对。忽视细节核对往往会导致单单不符、单货不符，从而延误清关时效并产生额外费用。

> 📖 分类：**单证**　｜　Debit Note = 借记通知单

## 定义
借记通知单（Debit Note）是货代或企业向客户（如发货人、收货人或代理）发出的一种结算凭证，用于通知对方其账户被记入借方，即要求对方支付额外的费用。在国际物流中，它通常作为补收运费、杂费或差额的正式索款依据。

## 详细说明
- 使用场景：主要用于原账单金额少计、漏计，或产生未预料的额外支出（如海关查验费、港口滞箱费、超重费、运费差额等）时向客户追缴款项。
- 关键规则或数字：Debit Note 并非正式发票（Invoice），不能直接用于企业的税务抵扣，但它是财务对账和开具最终发票的重要依据。通常需在账单上注明原账单号、费用明细及付款期限（如 Net 7 days）。
- 实务注意事项：货代在发放提单（B/L）或放货前，必须核对是否有未结清的 Debit Note，避免货物放行后出现坏账。同时，费用说明必须清晰透明，附上第三方凭证（如港口收据）以减少客户争议。

## 常见误区
- 误区一：认为 Debit Note 就是正式发票。实际上它只是一种通知或催款单，收款方最终需要依据它或汇总后开具增值税发票。
- 误区二：收到 Debit Note 后直接拒绝付款。部分从业者看到额外费用就本能拒付，而忽略了这可能是因货物实际重量超标或海关产生查验费等合理支出。

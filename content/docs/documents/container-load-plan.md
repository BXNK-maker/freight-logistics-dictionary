> 📖 分类：**单证** / 运输单证　｜　Container Load Plan = 集装箱装箱单

## 定义
Container Load Plan（简称 CLP，中文通常称为集装箱装箱单）是详细记录集装箱内部货物装载布局、位置及配载情况的专业单证。该文件由装箱人或场站制作，直观展示每件货物在箱内的具体三维坐标与堆码方式。它是保证海上运输安全、优化空间利用及方便海关查验的核心文件。

## 详细说明
- 使用场景：主要用于整箱货（FCL）装箱完毕后的记录，以及拼箱货（LCL）在集装箱货运站（CFS）配载时的规划。船公司、码头、海关和收货人均需参考此单。
- 关键规则或数字：装箱时必须严格遵循“重不压轻、下重上轻、重心平衡、防止偏载”的原则。危险品装载更需符合国际海运危险货物规则（IMDG Code）的隔离要求。
- 实务注意事项：CLP 上的货物重量和件数必须与提单（B/L）及商业发票保持一致。若因装箱不当（如偏载导致箱体受损或货物倒塌）引发事故，制单方需承担相应的法律与经济责任。

## 常见误区
- 误区一：认为 CLP 只是仓库的内部记录，与船公司或海关无关。实际上，海关查验时常依此单快速定位货物，不准确的 CLP 会导致查验延误。
- 误区二：将 Container Load Plan 与 Packing List（装箱单）混淆。Packing List 侧重于货物的品名、数量和箱规等商业信息，而 CLP 侧重于货物在集装箱内的物理空间布局与重量分布。

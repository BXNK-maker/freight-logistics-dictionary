> 📖 分类：**单证** / 运输单证　｜　Import Cargo Release Letter = 进口提货介绍信

## 定义

进口提货介绍信（Import Cargo Release Letter）是收货人或其委托的报关行向船公司、航空公司或其指定的货运代理人（如场站、仓库）出具的一份官方信函。该文件用于证明提货人的合法身份并请求放行指定的进口货物。它是传统国际物流中连接海关放行与仓库实物交货的关键凭证。

## 详细说明

- 使用场景：主要适用于传统海运拼箱货（LCL）、空运货物或部分散杂货的提货环节。在集装箱整箱（FCL）物流中较少直接使用纸质介绍信，通常通过电子设备交单（EDI）或设备交接单（EIR）替代。
- 关键规则或数字：介绍信通常需要加盖收货人公章（若为代提，还需加盖报关行公章），并附带提单（B/L）正本或副本、海关放行单等全套单证。文件有效期一般较短，通常随换单凭证在到港后数天内核发。
- 实务注意事项：随着无纸化通关和电子提单的普及，许多港口和航运代理已将此纸质流程升级为电子放货系统（e-Release）。但在处理某些特殊散货或特定发展中国家航线时，纸质介绍信仍是不可或缺的风险管控环节。

## 常见误区

- 误区一：认为进口提货介绍信可以替代提单。事实上，介绍信只是提货的辅助授权文件，收货人必须先凭有效提单换取提单正本或电放放货后，方可出具介绍信。
- 误区二：认为所有现代港口都需要纸质介绍信。目前绝大多数主要港口和航空公司已实现系统电子放行，纸质介绍信的使用范围正在逐年缩小。

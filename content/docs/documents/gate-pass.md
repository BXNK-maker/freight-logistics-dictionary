> 📖 分类：**单证**　｜　Gate Pass = 出门证

## 定义

Gate Pass（出门证）是货物或集装箱进出港区、堆场、仓库或海关监管场所时，经查验放行后开具的纸质或电子凭证。它是车辆和货物合法离开场站的通行证明，也是码头和门卫核对装载内容与单据相符的关键交接单据。

## 详细说明

- 使用场景：主要用于集卡司机在码头或堆场提货、还箱，或散货仓库发货时，凭此证通过大门卡口（Gate）。
- 关键规则：出门证通常在完成报关放行、海关查验、港杂费结算及设备交接单（EIR）确认后由系统自动生成或人工签发。门卫会核对车牌号、箱号、铅封号与证件信息一致后方可放行。
- 实务注意事项：司机必须妥善保管出门证，一旦丢失会导致车辆无法出闸，甚至需要重新走繁琐的补办和核销流程，从而产生额外的滞箱费或码头延时费用。

## 常见误区

- 误区一：认为 Gate Pass 等同于海关放行单。实际上，海关放行是海关层面的法律许可，而 Gate Pass 则是场站和码头内部的物流放行凭证，必须在海关放行后才能获取。
- 误区二：认为出门证可以随意涂改。出门证上的箱号、铅封号或车牌号若有任何手写涂改，门卫有权拒绝放行，必须由场站业务窗口盖章更正。

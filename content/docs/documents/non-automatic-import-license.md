> 📖 分类：**单证** / 贸易单证　｜　Non-Automatic Import License = 非自动进口许可

## 定义

非自动进口许可（Non-Automatic Import License）是政府主管部门为监管特定敏感货物的进口，要求进口商在货物装运前必须单独申请并获得批准的行政许可证明。与自动进口许可侧重于事后统计不同，非自动进口许可是一种实质性的贸易管制手段，海关凭此证放行货物。

## 详细说明

- 使用场景：通常适用于涉及国家安全、公共健康、环境生态保护、稀缺资源或是实施配额管理的商品，例如武器弹药、濒危动植物制品、部分化工原料及机电产品。
- 关键规则或数字：该许可证通常实行“一批一证”或“多批总证”管理，且有严格的有效期限制（一般为3到6个月）。若货物到港时许可证已过期的，将无法办理清关手续。
- 实务注意事项：货代和外贸人员必须在订舱和安排装运前，确认收货人是否已办妥非自动进口许可证。切勿盲目发货，否则极易导致货物在目的港滞港、产生高额滞箱费甚至面临被强制退运的风险。

## 常见误区

- 认为非自动进口许可可以像普通产地证那样在货物到港后再补办，实际上它必须在装运前取得。
- 混淆自动进口许可与非自动进口许可，误以为只要申请了就能自动获批，忽视了前者的统计属性与后者的审批属性有本质区别。

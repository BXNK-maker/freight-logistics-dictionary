## 定义

Return Reasons（退货原因）是指买家在电商购物或B2B贸易中将货物退回时，所填写的退货动机或归类标签。它是逆向物流（Reverse Logistics）管理中的核心数据，能够帮助货代和外贸企业精准追踪货物流向并优化供应链。

## 详细说明

- 使用场景：广泛应用于跨境电商退货处理、海外仓一件代发售后服务以及FBA（Fulfillment by Amazon）退货质检环节。
- 关键规则或数字：在处理海外仓退货时，常见的退货原因代码通常分为质量问题（如Defective，占比约30%-40%）、尺寸不符（Size too large/small）和未按预期送达（Late shipment）。系统会根据不同的 Return Reasons 自动触发后续指令，如直接销毁、重新上架或退运回国。
- 实务注意事项：货代与海外仓操作人员必须严格核对买家填写的退货原因与商品实际状态是否相符，这直接关系到关税退税申请、货损理赔责任划分以及商家的店铺绩效评估。

## 常见误区

- 误区一：认为 Return Reasons 只是买家的主观感受，对物流运营没有实质帮助。实际上，它是分析供应商产品质量和物流时效的重要数据来源。
- 误区二：所有退货原因都走相同的处理流程。不同的 Return Reasons 对应不同的售后方案，例如产品质量问题通常需要拍照取证并向工厂索赔，而“不想要了”则主要评估是否能直接二次上架。

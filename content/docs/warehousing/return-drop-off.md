> 📖 分类：**仓储** / 退货处理　｜　Return Drop-Off = 退货自寄点

## 定义
Return Drop-Off（退货自寄点）是指消费者在进行电商退货时，将需要退回的商品亲自送达至指定物理网点的物流服务模式。该节点通常依托便利店、邮局、快递柜或专属逆向物流服务点设立，是跨境电商和快递物流中降低逆向物流成本的重要环节。

## 详细说明
- 使用场景：主要应用于跨境电商B2C零售、独立站以及本土快递的售后退货流程，替代传统的上门揽收。
- 关键规则或数字：消费者通常需要在电商平台发起退货申请并获取退货条形码（Barcode）或二维码，在规定期限内（如7-14天）送达指定Return Drop-Off点，超时可能导致退货失效。
- 实务注意事项：货代与物流服务商需确保退货点具备扫码设备、暂存空间以及稳定的干线回收班次，同时要做好退货包裹的身份识别与标签防损，避免因条码模糊产生理赔纠纷。

## 常见误区
- 误认为Return Drop-Off就是丢弃点，实际上所有送达的退货包裹都需要经过清点、扫描并最终退回给卖家或海外仓。
- 认为消费者可以随意将退货送到任何快递网点，实际上必须是系统指定的特定Return Drop-Off合作网点才能完成退货交接。

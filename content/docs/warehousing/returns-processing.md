> 📖 分类：**仓储** / 退货处理　｜　Returns Processing = 退货处理作业

## 定义
Returns Processing（退货处理作业）是指物流企业或仓库接收、检查、分类、记录并重新处理客户退回商品的全套操作流程。它是跨境电商供应链和逆向物流（Reverse Logistics）中不可或缺的关键环节，直接影响库存周转率和客户满意度。

## 详细说明
- 使用场景：主要应用于跨境电商B2C履约中心、海外仓（Overseas Warehouse）以及B2B退换货场景，当海外消费者因尺码不合、质量问题或无理由退货时触发。
- 关键规则或数字：一般要求海外仓在收到退件后的24至48小时内完成拆包、拍照和系统扫描；质检标准通常分为直接上架、翻新维修、退回工厂和报废销毁四类。
- 实务注意事项：货代与仓库操作员必须严格核对RMA（Return Merchandise Authorization，退货授权）单号，防止无标包裹无法入库；同时需注意海关对退运商品的监管条件和税费核销问题。

## 常见误区
- 认为退货处理只是简单的收货入库，忽略了质检、翻新和系统数据同步的复杂性。
- 忽视退运商品的跨境税务与海关合规风险，导致无法顺利退运回国或在海外产生巨额滞港仓储费。

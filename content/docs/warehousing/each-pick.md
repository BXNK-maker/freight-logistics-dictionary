> 📖 分类：**仓储与配送**　｜　Each Pick = 单件拣货

## 定义
Each Pick，中文通常称为“单件拣货”或“拆零拣货”，是指仓库在处理出货订单时，从货架或存储位直接挑选单个最小包装单位（如单个商品、独立一件）的作业方式。这种模式无需按整箱（Case）或整托盘（Pallet）搬运，是满足现代电商碎片化、高频次订单需求的核心仓储环节。

## 详细说明
- 使用场景：广泛应用于B2C电子商务零售、跨境电商一件代发、医药零售以及多品类、小批量的B2B补货分拣作业。
- 关键规则与特点：操作对象是商品的最小销售单元（Each）；通常配合播种式拣货（Put-to-Light）或路线优化的手持终端（PDA）进行，以减少仓库内的无效步行距离。
- 实务注意事项：由于操作对象体积小、数量零散，Each Pick 的出错率相对整箱拣货更高，因此仓库通常需要引入条形码扫描（Barcode Scanning）或RFID技术来确保出货准确率，同时包装环节也需要增加耗材成本。

## 常见误区
- 误区一：认为 Each Pick 的效率一定比整箱拣货低。虽然单件拣货更为繁琐，但通过科学的波次策略（Wave Picking）和路径优化，依然可以实现高效的高并发处理。
- 误区二：将 Each Pick 与“分货（Sorting）”混淆。Each Pick 是从货位取货的动作，而分货通常发生在拣货之后，将多订单商品按客户归类。

> 📖 分类：**仓储** / 波次计划　｜　Order Release = 订单释放

## 定义

Order Release（订单释放）是指在供应链和物流管理中，企业内部系统（如ERP或WMS）将经过审核的客户订单正式下达到仓库、生产部门或物流供应商，启动后续作业指令的核心环节。它是连接前端商务销售与后端仓储运输的关键桥梁。

## 详细说明

- 使用场景：通常发生在信用审核通过、库存分配完成以及客户付款条件满足之后，标志着订单正式进入履约阶段。
- 关键规则与流程：释放前需核对库存可用性（ATP）、收货地址及交货期；一旦释放，系统通常会锁定相关库存，生成拣货单（Pick List）和出库任务。
- 实务注意事项：在国际货代业务中，若在货物装箱或报关前进行订单释放的变更或取消，会产生额外的操作成本和滞箱风险，因此多部门协同确认至关重要。

## 常见误区

- 误区一：认为订单创建就是订单释放。实际上，订单创建仅代表录入系统，而订单释放是经过风控和库存校验后才正式下达作业指令。
- 误区二：订单释放后可以随意修改数量。释放后的订单通常已被仓库锁定并开始物理作业，随意更改极易导致账实不符。

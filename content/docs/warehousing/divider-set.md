> 📖 分类：**仓储** / 存储容具　｜　Divider Set = 分隔板组

## 定义

Divider Set（分隔板组）是指用于航空货运主舱板或集装箱内部，将货舱空间进行物理分隔的配套板材与固定附件组合。它通常由多块轻质坚固的隔板及相应的卡槽、固定杆组成，旨在防止货物在运输途中发生位移或倒塌。


## 详细说明

- 使用场景：主要用于宽体货机的集装板（Pallet）或集装箱（ULD）装载，特别是混合装载不同尺寸、重量或包装性质的货物时。
- 关键规则或数字：分隔板需具备航空适航认证，其耐冲击强度必须符合国际航空运输协会（IATA）及各航空公司对 ULD 约束力的标准，以承受飞机起降及颠簸时的惯性载荷。
- 实务注意事项：货代在安排打板（Build-up）时，应确保 Divider Set 安装牢固且卡入正确槽位；若分隔重货与泡货（轻泡货），必须严格遵守前重后轻或左右平衡的配载原则，防止偏载影响飞行安全。

## 常见误区

- 误认为 Divider Set 仅用于美观或分类，忽视了其作为航空固定装置（Tie-down/Restraint）保障飞行安全的结构性作用。

> 📖 分类：**仓储** / 上架策略　｜　Cube per Order Index = 体积订单指数

## 定义

体积订单指数（英文全称：Cube per Order Index，简称 COI）是仓储规划与货位优化中用于评估货物存储分配优先级的基础量化指标。它定义为某种货物所需的存储空间（体积）与其订单需求频次（或拣选出库次数）的比值。该指标的核心目标是指导仓库作业动线，即 COI 值越低的货物，越应优先存放在距离出入库口最近的黄金位置，以最大程度缩短搬运距离并降低作业成本。

## 详细说明

- **使用场景**：广泛应用于集运仓、分拨中心（DC）以及跨境电商海外仓的货位规划（Slotting）与波次拣选设计。特别适用于 SKU 繁多、体积差异大且出库频次不一的复杂仓储环境。
- **关键规则与计算**：计算公式为 `COI = 货品存储体积 / 订单频次`。COI 值越小，代表该物品“占用空间越小、出库越频繁”，仓储周转性价比最高；因此在库位排布时，必须按 COI 数值由小到大、从出入口由近及远进行梯次存放。
- **实务注意事项**：外贸和跨境电商受促销、季节性影响明显，SKU 的出库频次处于动态变化中，需定期重新测算 COI 并调整库位（Re-slotting）；同时，实务中应用 COI 必须兼顾地面承重极限（Floor Load Capacity）、危险品隔离及冷链温区等物理约束，不可机械套用数学排序。

## 常见误区

- **误区一：认为 COI 数值越大越靠近出库口**。实际规则恰恰相反，COI 是体积除以频次，比值越低代表单位体积带来的作业效益最高，理应享有离月台最近的“黄金库位”。
- **误区二：将“订单频次”误当作“出货总量”**。分母关注的是触发拣货作业的“次数”，而非货物的总件数或总重量。单笔订单出库一万件（作业1次）与一千笔订单各出库一件（作业1000次），后者对拣选动线的占用极大，二者的 COI 计算差异显著。

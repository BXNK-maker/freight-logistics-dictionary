> 📖 分类：**仓储** / 上架策略　｜　Cube per Order Index = 体积订单指数

## 定义
体积订单指数（英文全称：Cube per Order Index，简称 COI）是仓储和物流管理中用于衡量订单体积特征的重要指标。它表示平均每个订单或每张出库单所需的平均货位体积或商品总体积，常用于优化仓库布局和货位分配。

## 详细说明
- 使用场景：主要应用于仓库规划、自动化立体库设计、拣货路径优化以及仓储费用的合理评估。
- 关键规则或数字：COI 通常通过总占用体积除以订单总数来计算。高 COI 意味着订单体积大，适合整托盘或整箱存储；低 COI 意味着订单体积极小，适合零担或拆零（Pick-and-Pack）高密度货架存储。
- 实务注意事项：在国际货代和分拨中心规划时，不能仅看货重，必须结合 COI 来评估货车装载率和集装箱空间利用率，以避免“运力空间富余但体积超限”或相反的情况。

> 📖 分类：**仓储** / 退货处理　｜　Return Policy = 退货政策

## 定义

退货政策（Return Policy）是指买卖双方或平台对商品退回的条件、时效、运费承担及处理流程所做出的明确规定。在国际物流与跨境电商中，它是逆向物流（Reverse Logistics）管理的核心依据，直接影响客户体验和供应链成本。

## 详细说明

- 使用场景：主要应用于跨境电商零售、海外仓一件代发以及B2B退换货业务，当买家因质量问题、尺寸不符或无理由拒收时触发。
- 关键规则或数字：常见的退货时效为30天内（30-day return window），部分平台要求提供无理由退货；

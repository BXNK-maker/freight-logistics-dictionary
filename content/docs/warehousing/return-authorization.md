> 📖 分类：**仓储** / 退货处理　｜　Return Authorization = 退货授权

## 定义

Return Authorization（退货授权，简称 RA 或 RMA）是指卖方或供应商同意买方退回货物的正式书面许可。它是逆向物流（Reverse Logistics）的起点，明确规定了退货的条件、批次、运费承担方及收货仓库。

## 详细说明

- 使用场景：主要应用于跨境电商售后、B2B贸易中瑕疵品召回、错发漏发补救以及海外仓退货换标（Labeling）业务。
- 关键规则与流程：买方必须在规定期限内（如签收后30天内）向卖家申请；RA号码通常需显眼地贴在外箱上，否则仓库有权拒收无标货物。
- 实务注意事项：货代在处理带有RA的退货时，必须核对RA单据与实际货物的SKU、数量是否一致，并明确由谁承担国际运费和关税，避免产生巨额滞港费。

## 常见误区

- 误区一：认为只要客户想退货就可以直接把货发回仓库。实际上，没有RA编号的货物到达仓库后往往无法入库，甚至会被直接销毁。
- 误区二：混淆RA与退货运单（Return Label）。RA是内部的授权凭证和管理代码，而退货运单是贴在包裹上用于运输的物流单据。

> 📖 分类：**仓储** / WMS功能　｜　System Configuration = 系统参数配置

## 定义
System Configuration（系统参数配置）是指在货运物流管理系统（如 TMS、WMS、ERP）中，根据企业实际业务规则、操作流程和合规要求，对软件系统的基础参数、权限及业务逻辑进行预设和调整的过程。它是确保物流软件能够正确处理订单、计费、报关及单证流转的核心前置工作。

## 详细说明
- 使用场景：主要应用于新系统上线初期、业务模式变更（如新增跨境电商仓储业务）、服务航线调整或对接新的EDI/API接口时。
- 关键规则或数字：配置通常涉及多级权限划分（如操作员、主管、财务）、费率计算公式设定、运单号生成规则以及系统对接的超时时间（如接口请求超时设定为30秒）等核心参数。
- 实务注意事项：系统配置直接影响后续的单证准确率和计费风控。物流企业在进行参数设定时，必须由业务运营骨干与IT技术人员共同参与，确保系统逻辑完全符合行业惯例及海关、税务等合规要求，避免因参数错误导致批量单证出错。

## 常见误区
- 误区一：认为系统配置是一劳永逸的工作。实际上，随着航线价格变动、客户协议更新及税率调整，系统参数需要定期维护和更新。
- 误区二：将系统配置完全甩给IT技术人员。由于技术人员往往缺乏一线货代实操经验，脱离业务实际的配置会导致系统落地后无法使用。

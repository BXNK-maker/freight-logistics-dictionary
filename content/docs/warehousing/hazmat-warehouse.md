> 📖 分类：**仓储与配送**　｜　Hazmat Warehouse = 危险品仓库

## 定义

危险品仓库（Hazmat Warehouse，全称 Hazardous Materials Warehouse，亦常称 DG Warehouse）是专门用于安全接收、存放和周转具有易燃、易爆、有毒、腐蚀或放射性等危险特性货物的特种仓储设施。此类仓库必须取得国家应急管理及消防等部门的特许经营资质，并配备防爆、防泄漏、恒温通风和自动化消防喷淋等专业防护系统。

## 详细说明

- **核心使用场景**：主要用于化工原料、农药、涂料、压缩气体以及新能源锂电池等进出口货物的口岸暂存、拼箱集运（LCL）及内陆分拨。
- **关键分类与规则**：储存严格基于联合国危险货物运输体系（UN Classification）的 9 大类划分；仓库必须根据产品的安全数据表（SDS/MSDS）执行严苛的隔离表（Segregation Table）制度，严禁互为禁忌的化学品（如酸与碱、强氧化剂与易燃液体）同库混放。
- **实务操作注意事项**：
  - 货物入库前，货代及货主须提供最新版 SDS、危包证及准确的 UN 编码，供仓库复核接收资质与库存容量。
  - 库内装卸与搬运必须使用防爆型叉车，作业人员须持有危化品操作资质证书，并严格穿戴防静电与防腐蚀护具。
  - 危险品仓库仓租及操作费通常远高于普通仓库，且受港区危排计划与堆存时限限制，实务中需精准协调清关与集港节奏，避免产生巨额超期费。

## 常见误区

- **误区一：只要是危险品仓库，就能接运所有类别的危险品**。实际上危险品仓库有极其严格的资质核准范围（如甲类、乙类仓库），多数仓库仅具备储存部分 Class 3（易燃液体）或 Class 9（杂项）的资质，极少能接存 Class 1（爆炸品）或 Class 7（放射性物质）。
- **误区二：锂电池产品货值高但无明火，可暂存普通仓库**。纯锂电池组或含锂电池设备（如 UN 3480、UN 3171）在国际规程中属于 Class 9 危险品，正规货运操作中严禁进入普通仓库违规堆放，否则面临严厉的行政处罚甚至扣货风险。

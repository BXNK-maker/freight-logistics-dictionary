> 📖 分类：**仓储与配送**　｜　Milk Run = 循环取货

## 定义

循环取货（Milk Run）是一种由货主或物流服务商派遣单一运输车辆，按预定路线和时间表依次前往多个供应商处收取货物，并最终送达生产厂或仓库的物流配送模式。该模式灵活性高、库存成本低，常用于汽车制造及精密零部件供应链。

## 详细说明

- 使用场景：适用于多供应商、小批量、高频次的零配件采购，特别适合制造企业实现 JIT（准时制）生产。
- 关键规则与运作：
  - 路线与时间固定：车辆必须严格按照设计好的时效窗口到各站点装货，通常实行“一车多点”闭环运输。
  - 容量与频次平衡：根据各供应商的产能和消耗速度计算最优发车频次和装载量，避免车辆空间浪费或供应商库存积压。
- 实务注意事项：
  - 协同管理：对各供应商的交货准备时间、包装规格（如统一使用标准周转箱）有极高的协同要求。
  - 应急预案：若某一供应商未能按时备货，可能导致整条取货路线延误，需制定备用应急方案。

## 常见误区

- 误区一：认为 Milk Run 就是传统的“拼货运输（LTL）”。LTL 侧重于零散货物的随机拼车，而 Milk Run 具有高度计划性、固定路线和专车循环的特点。
- 误区二：认为只要发货少就可以做 Milk Run。如果供应商地理位置过于分散或货量极度不稳定，反而会大幅增加空驶率和运输成本。

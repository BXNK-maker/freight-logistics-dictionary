> 📖 分类：**仓储** / 退货处理　｜　Return Shipping Label = 退货面单

## 定义

Return Shipping Label（退货面单）是指由发货人或电商卖家提供的、用于消费者将已购商品退回的专用物流运输标签。该面单上通常包含条形码或二维码、退货地址、承运商信息以及由物流商预付运费的追踪编码。

## 详细说明

- 使用场景：广泛应用于跨境电商、海外仓退货、B2C零售及逆向物流中，方便海外买家无需自行支付运费或手写地址即可将商品寄回。
- 关键规则或数字：退货面单通常有明确的有效期（如生成后30天内有效）和一次性使用限制；国际退货中，面单可能需要附加商业发票以协助海关清关。
- 实务注意事项：卖家应在后台为买家提供清晰的下载或打印指引，并与当地承运商（如USPS、UPS、DHL）确认退货面单是否为“免预付”或“到付”，避免产生巨额运费争议。

## 常见误区

- 认为退货面单上的运费是由买家承担：实际上绝大多数跨境退货面单是由卖家预付运费的，买家只需贴在包裹上交寄即可。
- 认为一张退货面单可以无限次使用：退货面单与特定追踪号绑定，通常只能使用一次，重复使用会导致丢件或额外扣费。

> 📖 分类：**仓储** / 自动化立库　｜　S/R Machine = 存取机

## 定义
S/R Machine 是 Stack/Retrieval Machine（堆垛机）的缩写，是自动化立体仓库（AS/RS）中最核心的起重搬运设备。它主要用于在立体货架的巷道中进行货物的自动存入、取出以及移位作业，极大提升了物流仓储的空间利用率和作业效率。

## 详细说明
- 使用场景：广泛应用于现代化的高位立体仓库、大型分拨中心、保税物流园区以及第三方物流（3PL）的自动化存取环节。
- 关键规则或数字：根据巷道类型可分为单立柱和双立柱结构；运行速度通常可达每分钟数百米，定位精度控制在毫米级，以确保在高层货架间安全作业。
- 实务注意事项：在日常操作中需定期维护轨道和激光测距系统，防止因机械磨损导致定位偏差；同时应注意货物的极限载重和外形尺寸，避免超限卡死在巷道中。

## 常见误区
- 误认为 S/R Machine 就是普通的叉车，实际上它是沿着固定巷道轨道运行的自动化专用设备，无法在平面自由转弯。
- 忽略了货载尺寸的合规性，认为只要重量不超标就能随意存入，导致货物超宽或超高而撞击货架或设备。

> 📖 分类：**仓储** / WMS功能　｜　Cycle Count Request = 循环盘点任务

## 定义

Cycle Count Request（中文：循环盘点任务）是指仓库管理系统中向盘点人员下发的、对特定库存货位或SKU进行周期性清点和核对的指令。它是动态库存管理的重要手段，旨在不中断日常出入库作业的前提下，分批验证账面库存与实际库存的相符性。

## 详细说明

- 使用场景：通常在仓库日常运营中按ABC分类法定期触发，或在发现库存差异、处理异常订单、以及大促前后进行重点库存抽查时由WMS系统自动生成或由主管手动下发。
- 关键规则或数字：循环盘点一般遵循“高价值或高周转商品盘点频次更高”的原则（如A类商品每周盘点，C类商品每季度盘点）；盘点过程要求做到“账、卡、物”三者相符，差异率通常需控制在极低范围内（如0.5%以内）。
- 实务注意事项：下发任务时需合理规划盘点路线，避免干扰叉车作业和拣货路径；盘点期间应尽量锁定对应货位的动态库存（如暂停上架和移库），确保清点数量的准确性。

## 常见误区

- 误认为循环盘点可以完全替代年底的全盘（Physical Inventory）：事实上，循环盘点侧重于日常高频纠错和局部抽查，通常无法替代法定或年度的大规模全面盘点。
- 误以为循环盘点任务会严重影响仓库发货效率：合理的循环盘点任务通常按区域或小批量下发，旨在利用碎片时间作业，不会导致日常订单履约停滞。

## 这是什么

「货运物流字典」是一个中英对照的货运物流术语词典，帮助外贸、货代、物流从业者快速查询和理解行业术语。

## 内容是怎么来的

本站采用全自动化流水线运营：

1. **术语表驱动**：维护在仓库 `terms/terms.csv` 中
2. **AI 生成初稿**：GitHub Actions 定时调用 Gemini，按术语表批量生成词条 Markdown
3. **人工审核**：生成的词条以 Pull Request 形式提交，维护者审核合并后才会上线
4. **自动发布**：合并后 HugoBlox 自动构建并部署到 GitHub Pages
